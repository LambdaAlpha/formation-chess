# 阵棋 —— 游戏规则

本文描述标准对局：9×10 棋盘，红黑双方各有 16 枚互不重复的棋子，从空棋盘开始布阵，红方先行。自定义棋盘和局面快照的文本格式见 `docs/notation.zh-Hans.md`。

## 目标与流程

阵棋是一款以局部阵法影响为核心的双人抽象策略游戏。目标是让对方不再拥有带有**首领**能力的棋子。标准棋子中，每方的将（`将`）是唯一的首领棋子。

阵棋没有九宫、楚河、将军或将死。将按普通棋子的规则移动和互动，也可能被捉、在暗捉后被移除，或与另一枚棋子同归于尽。

标准对局分为两个阶段：

1. **布阵阶段**：红黑双方轮流把全部棋子放入己方半场。
2. **行棋阶段**：双方轮流执行一个行棋行动。

每个行动的合法性与效果都以完整的行动前局面为准。相关棋子的**有效能力**在该局面中确定，并用于本次行动；位置变化生效并切换行棋方后，再根据首领棋子的存续状态判断对局是否结束。

## 棋盘与布阵

### 棋盘坐标

标准棋盘有 9 列、10 行。列号从左到右递增，行号从上到下递增。坐标始终按“列、行”书写；文本记谱中的 `三二` 表示第 3 列第 2 行。

- 黑方半场是第 1–5 行，黑方向行号增大的方向前进。
- 红方半场是第 6–10 行，红方向行号减小的方向前进。
- 所有位置使用同一套几何规则，不存在特殊区域。

自定义棋盘可以是 1×1 到 16×16 的矩形。棋盘高度为奇数时，中间行不属于任何一方的布阵半场。

### 布阵阶段

标准对局从空棋盘开始，双方棋池均为：

```text
将 计 势 变 风 林 火 山 矛 盾 弹 雷 士 卒 马 车
```

红方先布阵，之后双方严格交替。每次布阵从当前玩家的棋池取出一枚棋子，放到己方半场的一个空点。

- 同一枚棋子不能重复放置。
- 红方不能放置黑方棋子，黑方也不能放置红方棋子。
- 当前玩家可以在布阵阶段认负。

标准对局由黑方放完最后一枚棋子。此时双方棋池都为空，进入行棋阶段，并由红方行动。

## 能力与有效能力

棋名只表示棋子的身份，并不单独决定走法。每枚棋子都有一组**基础能力**；周围棋子的阵法会临时改变其中部分能力，形成判断行动是否合法时使用的**有效能力**。

“友方”和“敌方”按棋子的所属玩家（红或黑）判断，不按当前控制权判断。即使黑方能够指挥一枚红子，这枚红子对其他红子仍是友方。

| 能力 | 含义 |
|---|---|
| **主动** | 棋子的所属方可以指挥这枚棋子。 |
| **被动** | 棋子的敌方可以指挥这枚棋子。 |
| **推友** | 主动推动友方棋子的权限。 |
| **推敌** | 主动推动敌方棋子的权限。 |
| **友推** | 被友方棋子推动的权限。 |
| **敌推** | 被敌方棋子推动的权限。 |
| **拉友** | 主动拉动友方棋子的权限。 |
| **拉敌** | 主动拉动敌方棋子的权限。 |
| **友拉** | 被友方棋子拉动的权限。 |
| **敌拉** | 被敌方棋子拉动的权限。 |
| **暗捉** | 发动推动；目标无路可退时，推动转为捉子。 |
| **易捉** | 被发动推动；自身无路可退时，被推动转为捉子。 |
| **明捉** | 发动捕捉；目标有后续落点时，捕捉转为推动。 |
| **难捉** | 被发动捉子；自身有后续落点时，被捉转为被推。 |
| **捕捉** | 发动普通捕捉的权限。 |
| **被捉** | 成为普通捉子行动目标的权限。 |
| **强捉** | 无视目标的“被捉”，强行发动捉子；发动方同时离场。 |
| **反捉** | 被捉时同时捉掉攻击方，并允许没有“捕捉”的棋子发动本次捉子。 |
| **疾行** | 沿同一移动方向连续行进任意步数。 |
| **纵横** | 横向或纵向移动。 |
| **交错** | 沿对角线移动。 |
| **阔步** | 按日字方向移动。 |
| **首领** | 计入所属方存亡条件的棋子；所属方失去全部“首领”时落败。 |
| **议和** | 与敌方“首领”交换位置并立即达成和棋。 |

阵法效果只取决于当前局面，生效条件消失后不会继续保留。行动完成后，新位置会产生新的有效能力。只有到达目标点后才获得的能力，不能反过来让刚才的行动合法。

## 阵法

### 局部阵形

阵法只影响阵主周围八个相邻位置中的一部分。`O` 表示阵主，`X` 表示生效点。下图采用红方朝向。

```text
     四角                       四边
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+

    上三角                      下五角
+---+---+---+              +---+---+---+
|   | X |   |              | X |   | X |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
```

黑方阵法按垂直方向翻转。四角和四边翻转后不变；黑方的三角尖端向下，黑方机动组使用向上五边形。正、反两种五边形是同一机动组阵形的双方朝向。阵法永远不会影响中心的阵主自身。

| 分组 | 棋子 | 阵形   |
|---|---|--------|
| **兵法组** | `将 计 势 变` | 四角   |
| **牵制组** | `风 林 火 山` | 四边   |
| **攻守组** | `矛 盾 弹 雷` | 上三角 |
| **机动组** | `士 卒 马 车` | 下五角 |

### 多阵法叠加

同一枚棋子受到的所有相邻阵法都以同一个行动前局面为基础同时生效。

- 每个阵法只影响特定能力。
- 多个阵法对同一能力意见不一致时，关闭能力的一方优先。
- 不同能力彼此独立合并。
- 控制能力也遵循同一规则。友敌关系以每枚棋子的所属方为参照，因此棋子可能同时受双方控制，也可能不受任何一方控制。

## 移动几何

行棋阶段从棋盘起点发动行动时，必须同时满足：

- 对局尚未结束，且当前处于行棋阶段；
- 当前玩家能够控制起点棋子的有效状态；
- 目标在棋盘内，且不等于起点；
- 棋子拥有匹配的有效方向；
- 移动距离符合能力；
- 所有路径点和阔步腿位都畅通。

三种方向为：

- **纵横**：横向或纵向一步。
- **交错**：沿对角线一步。
- **阔步**：一个马步，且对应直线腿位为空。

拥有**疾行**时，可以重复同一个步进向量。纵横和交错长距离移动不能穿过棋子；长距离阔步移动会沿同一条 1:2 斜率连续走马步，每个中间落点和每个腿位都必须为空。

普通移动和拉要求目标为空；捉、推、和要求目标有棋子。行动声明的意图本身就是规则的一部分，到达有子位置并不会自动决定采用哪种互动。

## 行棋行动

### 移动

受控制的棋子移动到空点，不改变其他棋子。

### 捉

捕捉首先要求移动几何合法，且目标点有棋子。捕捉不限制双方所属：只要权限成立，同色棋子也可以互捉。

满足以下任一条件即可获得捕捉权限：

- 攻击方有**捕捉**，目标有**被捉**；
- 攻击方有**强捉**；
- 目标有**反捉**。

权限成立后，再检查捕捉降级。若攻击方有**明捉**，或目标有**难捉**，并且目标点之后的一步是合法落点，则本次捕捉变为推动，不再检查普通推动权限。若该落点不合法，则仍按捕捉结算。

最终按捕捉结算时，攻击方占据目标点，目标离开棋盘。强捉与反捉仅在通过这两个能力本身发动的捕捉中生效：若攻击方有“捕捉”且目标有“被捉”，则按普通捕捉结算，双方都不会被移除；暗捉触发的捕捉始终按普通捕捉结算（见推）。

### 推

推动方占据有子目标点，目标沿相同移动向量再前进一步。目标自身不需要对应移动方向，因为推动提供外力；但目标落点必须在棋盘内、为空，并在阔步推动时满足腿位畅通。

- 推友：推动方有**推友**，或目标有**友推**，任一成立即可。
- 推敌：推动方有**推敌**，且目标有**敌推**，两者必须同时成立。

目标没有合法落点时，推动受阻。若推动方有**暗捉**，或目标有**易捉**，推动升级为捉子。该升级绕过普通“捕捉”“被捉”和同异色限制，且始终按普通捉子结算：推动方占据目标点，目标离开棋盘，强捉与反捉均不生效。没有升级能力时，行动非法。

### 拉

主动棋子先移动到一个空目标点；位于起点后方、与主动移动向量相反一整步的位置上的棋子，被拉入刚刚空出的起点。

- 拉友：主动方有**拉友**，或目标有**友拉**，任一成立即可。
- 拉敌：主动方有**拉敌**，且目标有**敌拉**，两者必须同时成立。

被拉棋子自身不需要对应移动方向。其来源位置必须在棋盘内且有棋子；阔步拉还要求来源到起点的腿位畅通。来源缺失或受阻时行动非法。拉不会转换为捉或推。

### 和

和棋行动使用普通移动几何和路径检查，但不使用“捕捉”或推动相关权限。

- 主动棋子必须属于当前玩家，不能只是被当前玩家控制的敌方棋子。
- 主动棋子必须拥有**议和**能力。
- 目标必须是对方所属的首领棋子。

行动成功后，两枚棋子交换位置，结果立即设为和棋。双方都不会离开棋盘，也不会再用物质变化或首领移除结果覆盖这个结果。

### 认负

**认负**在行棋阶段是一个带目标的行动。目标必须是当前玩家能够控制的首领棋子；目标棋子的所属方失败，另一方获胜。通常玩家会让自己的将认负；若`计`使当前玩家能够控制对方的将，也可以让对方的将认负。布阵阶段则由当前玩家直接认负，不需要选择盘上目标，并由当前玩家失败。

本规则不会因为重复局面或用时自动结束。比赛规程可以另行增加这些终局条件。

## 标准棋子

基础能力按**所有棋子共性 → 分组共性 → 棋子特性**确定，后面的规则覆盖前面的规则。

### 所有棋子共性

所有标准棋子默认具有主动、被捉、敌推、敌拉；其他能力默认不具备。

### 分组共性

| 分组 | 棋子 | 阵形 | 增加的能力 |
|---|---|---|---|
| **兵法组** | `将 计 势 变` | 四角 | 交错、疾行、推友、推敌、友推、敌推、拉友、拉敌、友拉、敌拉 |
| **牵制组** | `风 林 火 山` | 四边 | 纵横、疾行、推友、推敌、友推、敌推、拉友、拉敌、友拉、敌拉 |
| **攻守组** | `矛 盾 弹 雷` | 红方上三角；黑方下三角 | 一步阔步、捕捉 |
| **机动组** | `士 卒 马 车` | 正、反五边形：红方向下，黑方向上 | 捕捉 |

### 棋子特性

每枚棋子自身获得其阵法授予友方的能力，并失去其阵法从友方移除的能力；这一规则可以覆盖全体默认。除此之外，只有将具有首领，车额外具有纵横。

| 棋子 | 阵法效果 |
|---|---|
| **将** | 友方获得议和；敌方失去议和 |
| **计** | 敌方获得“被动”；友方失去“被动” |
| **势** | 友方获得“暗捉”、失去“易捉”；敌方相反 |
| **变** | 友方获得“难捉”、失去“明捉”；敌方相反 |
| **风** | 友方获得“拉友”“拉敌”；敌方失去“拉友”“拉敌” |
| **林** | 友方获得“友拉”、失去“敌拉”；敌方获得“敌拉”、失去“友拉” |
| **火** | 友方获得“推友”“推敌”；敌方失去“推友”“推敌” |
| **山** | 友方获得“友推”、失去“敌推”；敌方获得“敌推”、失去“友推” |
| **矛** | 友方获得“捕捉”；敌方失去“捕捉” |
| **盾** | 友方失去“被捉”；敌方获得“被捉” |
| **弹** | 友方获得“强捉”；敌方失去“强捉” |
| **雷** | 友方获得“反捉”；敌方失去“反捉” |
| **士** | 友方获得“交错”；敌方失去“交错” |
| **卒** | 友方获得“纵横”；敌方失去“纵横” |
| **马** | 友方获得“阔步”；敌方失去“阔步” |
| **车** | 友方获得“疾行”；敌方失去“疾行” |

## 回合完成与终局

合法行动会使规定的变化生效，并切换行棋方。非法行动不会改变棋盘、棋池、行棋方或胜负。

除和棋行动与认负外，其余行动根据行动后双方是否仍保有首领棋子决定结果：

- 双方都不再保有首领棋子：和棋；
- 只有黑方保有首领棋子：黑胜；
- 只有红方保有首领棋子：红胜；
- 双方都保有首领棋子：对局继续。

仍在布阵棋池中的首领棋子也算保有。一旦胜负不再是`未分`，任何后续行动都不合法。

## 局面检查顺序

1. **先看控制权。**棋子所属方与控制方不是一回事；`计`可能让玩家指挥对方棋子。
2. **看有效能力，不只看棋名。**阵法可能移除熟悉的移动或战斗能力，也可能把它授予其他棋子。
3. **先检查几何。**确认主动路径、每个阔步腿位、推动落点和拉动来源。
4. **完成转换后再计算交换。**受阻推动可能变捉，捕捉可能因明捉或难捉转为推动，弹与雷还可能让双方同时离场。
5. **行动后重新计算阵法。**主动棋子或被外力移动的棋子换位，都可能一次改变多项能力。
6. **持续检查首领、和棋交换和认负目标。**这些机制不一定通过普通捉走当前玩家自己的将来结束对局。

## 术语表

- **所属方**：棋子标记的红方或黑方。
- **控制**：当前局面中哪一方可以指挥一枚棋子。
- **友方 / 敌方**：同所属方 / 异所属方关系，与控制权无关。
- **基础能力**：棋子在不受阵法影响时具有的能力。
- **有效能力**：基础能力与当前所有相邻阵法效果合并后的结果。
- **阵法**：棋子向相邻特定位置投射的局部能力效果。
- **布阵棋池**：一方尚未进入棋盘的棋子。
- **行动意图**：明确声明的移动、捉、推、拉或和。
- **首领**：用于决定所属方存亡的能力。
