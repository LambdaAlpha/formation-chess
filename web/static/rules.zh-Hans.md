## 设计理念

在大多数棋类游戏里，棋子的名字就决定了它是什么：象走斜线、马走日字——身份是固定的，对局在这些固定身份的互动中展开。阵棋采用了不同的思路。每枚棋子都投射一个**阵法**——覆盖自身周围区域的专属影响力场。站在他人阵法之内的棋子，其能力会被暂时重塑：可能获得新的力量，也可能失去原本拥有的能力。

这意味着没有任何棋子永远"只是它自己"。卒站在车旁，忽然就能不限距离地滑行；将的身边若全是失去捉子能力的敌人，它便固若金汤。棋盘上的影响力此消彼长，每一步都会重构局部的力量之网。

规则中没有任何绑定在棋子名字上的逻辑——一切机制皆是**能力**。马并非"因为是马所以走日字"，它只是默认携带日字移动能力。任何站在马的阵法中的棋子都可以获得同样的日字移动。规则只关心能力，不关心名字。

## 如果你会下象棋

阵棋沿用了象棋的 9×10 棋盘和许多熟悉的棋子名称——车、马、卒、将、士——以及一个标志性机制：马腿会被蹩住。

除此之外的一切都不同。没有九宫，没有楚河汉界，也没有固定开局——军队由你亲手布置。棋子没有固定的本领：一枚棋子能做什么，由它所处的阵法决定。没有将军与将死——将像普通棋子一样被捉，失去将即输掉对局。被捉的棋子也不会永远退场：它们化为白子，可被任意一方的巫重新召回棋盘。

## 基础

对局在 **9 路 × 10 行的棋盘**上进行，双方为**红方**与**黑方**。每名玩家统率 **16 枚各不相同的棋子**。此外还有第三种颜色——**白色**，属于被捉后可重新部署的棋子（见[白子](#白子)）。

棋盘上的位置写作（列，行）：列号 1–9 自左向右，行号 1–10 自上而下。黑方在棋盘上方作战（第 1–5 行），红方在下方（第 6–10 行）。

对局分两个阶段：双方先把所有棋子**布置**上盘，然后**行棋**。**红方先行**，双方严格交替，每回合一个行动，从第一步布子直到对局结束。

## 能力

每枚棋子都拥有一组决定其行为的**能力**。能力并非一成不变——它们会被阵法改写。完整的能力列表：

| 能力 | 效果 |
|---|---|
| **控制（红 / 黑）** | 决定哪名玩家可以指挥这枚棋子。只有受你控制的棋子才能由你移动。 |
| **推动友方** | 可以把友方棋子沿移动方向再推一步。 |
| **推动敌方** | 可以把敌方棋子沿移动方向再推一步。 |
| **可被友方推动** | 可以被友方棋子推动。 |
| **可被敌方推动** | 可以被敌方棋子推动。 |
| **推转捉** | 这枚棋子推动目标时，若目标无法落到被推落点（落点被占、出界、或目标到被推落点的路径上有棋子阻挡），推动转为捉子——将目标移出棋盘，无视目标的能力和颜色。 |
| **被推转被捉** | 这枚棋子被推且无法落地时，推动方将其捉走。 |
| **捉转推** | 这枚棋子捉子时，若移动方到目标之间的路径上没有中间棋子阻挡，捉子转为推动——将目标沿移动方向再推一步，而非将其移出棋盘。 |
| **被捉转被推** | 这枚棋子被捉且攻击方到它之间的路径畅通时，它被推开而非被捉走。 |
| **捉子** | 可以走入敌方棋子所在点并将其移出棋盘。 |
| **可被捉** | 可以被敌方棋子捉走。 |
| **被捉反杀** | 这枚棋子被捉时，捉它的棋子同归于尽。同时也使没有捉子能力的棋子也能捉走它。 |
| **捉子同亡** | 这枚棋子捉子时，自身一并阵亡。同时也使没有可被捉能力的棋子也能被它捉走。 |
| **任意距离** | 沿允许的方向可滑行任意步数，而非只走一步。 |
| **方向：十字** | 可以横向或纵向移动。 |
| **方向：斜向** | 可以沿对角线移动。 |
| **方向：日字** | 可以按日字（马步）移动。 |
| **控制白子** | 可以把白子池中的白子放置到自身阵法内的空点上。指挥已放置的白子则由巫的阵法效果另行授予。 |
| **要害** | 失去携带此能力的棋子即告负。将默认携带它。 |
| **和棋** | 可以走入对方要害棋子所在的位置，移除对方棋子并宣布和棋。将由自己的阵法授予友军，自身同样携带。 |

## 阵法

每枚棋子都在以自身为中心的 3×3 区域上投射**阵法**。站入这片区域的棋子可能被改写能力。但阵法并非均匀的力场：其中只有特定位置生效，具体哪些位置取决于棋子的**阵形**。

阵形共有四种：

```
     四角                       四边
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+

    上三角                      下三角
+---+---+---+              +---+---+---+
|   | X |   |              | X |   | X |
+---+---+---+              +---+---+---+
|   | O |   |              |   | O |   |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
```

`O` 是站在中心的阵法主人；`X` 是生效的位置。图中阵形以红方视角绘制（红方位于棋盘下方，向上方推进）。黑方位于棋盘上方并向下方推进，因此其阵形会上下颠倒：黑方的上三角指向下方，下三角指向上方。

每种阵形对应一组四枚棋子：

- **四角** —— 控制组：将、巫、间、谍
- **四边** —— 移动组：车、卒、士、马
- **上三角** —— 推动组：风、山、火、林
- **下三角** —— 攻杀组：矛、盾、弹、雷

可以这样理解：棋子的影响力以特定的**形状**向外辐射。四角棋子沿对角线施加影响，如同居于侧翼纵览战场的主帅；四边棋子沿正方向施加影响，如同扼守四方要道的步兵。三角阵形则是不对称的：上三角覆盖正前方与后方两翼，下三角覆盖前方两翼与正后方。"前方"始终是棋子主人向对手推进的方向。

**阵法叠加的合成规则：**当多个阵法试图修改同一枚棋子的同一项能力时，遵循"**只要有阵法禁用该能力，禁用即获胜**"的规则合成。哪怕只有一个阵法剥夺了某项能力，其他阵法也无法将其恢复。禁用是绝对的。

## 移动

棋子只能沿其**方向**能力所启用的方向移动。方向共有三类：十字（横/纵）、斜向、日字（马步）。

默认情况下，每个方向只能移动**一步**：

- 十字：向左、右、上、下移动一点。
- 斜向：沿对角线移动一点。
- 日字：走一个马步。

拥有**任意距离**能力后，棋子可沿允许的方向滑行任意点数。对日字移动而言，这意味着沿同一条斜线连续接力马步。

棋子必须至少拥有一个方向能力才能移动。敌方阵法可以剥夺方向能力——一旦离开友方掩护误入敌阵，随时可能动弹不得。**务必保持你的阵法网络完整**，让友军彼此支援。

## 推动与捉子

这些互动由成对的能力共同约束。

**推动**是指把目标棋子沿你的移动方向再往前送一步。推动是外力：被推的棋子被视为拥有所需的方向能力，其自身的移动能力无关紧要。

- 推动**友方**棋子：你拥有*推动友方***或**目标拥有*可被友方推动*，任意一方同意即可。
- 推动**敌方**棋子：你拥有*推动敌方***且**目标拥有*可被敌方推动*，双方条件缺一不可。

**推动受阻时。**当被推棋子无法落地——落点被占、出界、或从被推棋子当前点到落点之间的路径上有棋子阻挡——推动受阻。正常情况下，受阻的推动失败。然而，若推动方拥有*推转捉***或**目标拥有*被推转被捉*，推动转为捉子：推动方占据目标原来的位置，目标被移出棋盘，无视目标的能力和颜色。这是火阵形的领域。

**普通捉子**是指走入敌方棋子所在的点并将其移出棋盘。你需要*捉子*，目标需要*可被捉*，且双方颜色不同。从移动方到目标之间的路径上不能有棋子阻挡。

**捉子转为推动时。**若移动方到目标之间路径畅通（没有中间棋子阻挡），且捉子方拥有*捉转推***或**目标拥有*被捉转被推*，捉子转为推动：捉子方将目标沿移动方向再推一步，而非将其移出。若推动本身受阻（推的落点无效），行动退回普通捉子——推动尝试不会导致错误。这是林阵形的领域。

**互毁：**捉子完成后，可能触发两种效果：

- 若目标带有*被捉反杀*，捉子方一并被移出棋盘。此效果同时使没有捉子能力的棋子也能触发反杀。
- 若捉子方带有*捉子同亡*，捉子方一并被移出棋盘。此效果同时使捉子方能捉走没有可被捉能力的目标。

这两种效果对任何站在授予它们的阵法之内的棋子都生效，而不仅限于默认携带者。

### 日字移动的特殊情形

日字移动是跃过一个中间点抵达终点，而非贴着棋盘滑行，因此有两处机制略有不同：

**蹩马腿。**日字移动在通往终点的路上会经过一个中间点。例如从 (1,1) 走到 (2,3) 会经过 (1,2)。若该点被棋子占据，移动便被阻挡——马腿被蹩住了。腿位上有任何棋子都会阻塞移动。

**用日字移动推子。**用日字移动推动目标时，目标沿同一方向再走一个马步。例如从 (1,1) 往 (2,3) 方向推，目标落到 (3,5)。被推棋子走这一步如同自己移动——无须拥有日字能力，但马腿按被推棋子自身的路径规则判定：若腿位被占据或落点被占，推动受阻，可能转为捉子，如果任一方有相关的推阻变捉能力（见上文）。

## 棋子

每方拥有 16 枚各不相同的棋子，按阵形分为四组。

默认情况下，所有红黑棋子均带有*可被敌方推动*、*可被捉*；例外是**山**（不可被敌方推动），以及**盾**（不可被捉）。除非阵法改写这些设定，大多数棋子都可以被敌方推动与捉走。

### 分组共性

每组棋子共享一套基础能力。下表列出各组的默认共性；个别棋子可在共性之上增加或改写。

| 组别 | 阵形 | 共性能力 |
|---|---|---|
| 控制组 | 四角 | 十字、任意距离、推动友方、推动敌方 |
| 移动组 | 四边 | 捉子 |
| 推动组 | 上三角 | 斜向、任意距离 |
| 攻杀组 | 下三角 | 日字、任意距离 |

以下各节中，每枚棋子的独立表格仅列出其**区别性**特征——即与上表共性不同的部分——外加阵法效果。

### 控制组 —— 四角阵形

这一组棋子关乎**谁控制什么**。

| 棋子 | 区别性特征 | 阵法效果 |
|---|---|---|
| **将** | *要害*、*和棋* | 授予阵内友军*和棋*，剥夺敌方*和棋* |
| **巫** | *控制白子* | 阵内白子受巫所属玩家控制 |
| **间** | — | 阵内敌子**同时**受间所属玩家控制（策反）；阵内友军移除对手的控制（清除渗透） |
| **谍** | 双方玩家皆可控制 | 阵内友军**同时**可被对手控制（双面间谍效果）；阵内敌子移除谍所属玩家的控制（撤回己方对敌子的控制） |

**将**是你的要害棋子——失去将即告负。它行动自由，但不能捉子，请用阵法保护它。它的阵法授予阵内友军*和棋*能力、剥夺敌军*和棋*能力，使友军可以走入对方将所在的位置宣布和棋（见[终局](#终局)）。将自身同样携带此能力，可以直接走向对方将。

**巫**让阵亡的棋子重返战场：它把白子放置到自身阵法内的空点上，而站在其阵法内的白子听命于巫所属的玩家。见[白子](#白子)。

### 移动组 —— 四边阵形

这一组棋子携带各自名号的移动方向，并**将其授予友军、从敌军身上剥夺**。

| 棋子 | 区别性特征 | 阵法效果 |
|---|---|---|
| **车** | 十字、任意距离 | 友军获得任意距离；敌军失去之 |
| **卒** | 十字 | 友军获得十字移动；敌军失去之 |
| **士** | 斜向 | 友军获得斜向移动；敌军失去之 |
| **马** | 日字 | 友军获得日字移动；敌军失去之 |

这一组棋子是全军机动力的支柱，而且彼此支援：除车以外它们默认一步一步地走，但站在友方车的旁边就能获得无限射程。车的阵法还能钉子：阵内的敌方棋子会失去滑行能力。

### 推动组 —— 上三角阵形

这一组棋子专精于**推动机制**，全部沿斜向任意距离移动。

| 棋子 | 区别性特征 | 阵法效果 |
|---|---|---|
| **风** | *推动友方*、*推动敌方* | 友军获得两种推动能力；敌军两者皆失 |
| **山** | *可被友方推动*、**无***可被敌方推动* | 友军：仅可被友军推动；敌军：仅可被山的一方推动 |
| **火** | *推动友方*、*推动敌方*、*推转捉* | 友军获得*推转捉*、失去*被推转被捉*；敌军获得*被推转被捉*、失去*推转捉* |
| **林** | *被捉转被推* | 友军获得*被捉转被推*、失去*捉转推*；敌军获得*捉转推*、失去*被捉转被推* |

风赋能周围的棋子去推动；山完全接管周围棋子"如何被推动"的方式，把两项"可被推动"能力一并改写，敌我皆然。火和林分别控制推阻和路径畅通时的行为转换——火让受阻的推动变为捉子，林让畅通的捉子变为推动。

### 攻杀组 —— 下三角阵形

这一组棋子专精于**捉子与战斗**，全部沿日字方向任意距离移动。其中只有矛自带*捉子*能力；盾、弹、雷自身不能捉子，依赖阵法或互毁机制来互动。盾没有*可被捉*——它是全场唯一对普通捉子免疫的棋子，只能通过互毁或推转捉来移除。

| 棋子 | 区别性特征 | 阵法效果 |
|---|---|---|
| **矛** | *捉子*、*可被捉* | 友军获得捉子；敌军失去之 |
| **盾** | 无*可被捉* | 友军去掉*可被捉*（免疫）；敌军获得*可被捉* |
| **弹** | *捉子同亡* | 友军获得*捉子同亡*；敌军失去之 |
| **雷** | *被捉反杀* | 友军获得*被捉反杀*；敌军失去之 |

**矛**是本组中唯一自带*捉子*的棋子，其阵法为友军授予捉子、为敌军剥夺捉子。**盾**自身不可被捉，让身边所有人都获得免疫——让盾靠近你的将，叠上一层保护。**弹**携带*捉子同亡*：若通过友方矛的阵法等方式获得了*捉子*能力后进行捉子，自身也一并阵亡。此效果可绕过目标的*可被捉*——它能捉走盾。**雷**携带*被捉反杀*：任何捉它的棋子同归于尽。即使没有*捉子*能力的棋子踩上来也会触发——如同一颗陷阱。

## 白子

任何棋子因战斗被移出棋盘——无论是被捉走，还是死于互毁效果——都会化为共享白子池中的一枚**白子**。白子拥有十字、斜向、日字方向任意距离移动，任何人都可以捉它，它自己不能捉子。

拥有**控制白子**能力的棋子（巫）可以把白子池中的白子放置到其阵法内的任意空点。白子自身不带任何控制权：它们通过巫的阵法受指挥——站在巫的阵法内的白子可由该巫所属的玩家移动（若双方的巫同时覆盖它，则双方都能移动它）；不在任何巫的阵法内的白子无法被移动。捉走白子会将其送回白子池——白子是循环使用的，不会被消灭。

这为游戏增加了第三个维度：被你捉走的敌子化为白子，可被我方巫重新部署。不过白子不受阵法效果影响，战力远不如原棋子——主要用于占位和阻挡。

## 对局流程

**布阵阶段。**对局从空棋盘开始。自红方起，双方轮流每回合把一枚己方棋子放置到己方半场的任意空点上：红方放在第 6–10 行，黑方放在第 1–5 行。此阶段不允许按兵，也不能放置白子——每个回合都必须放置己方 16 枚棋子中的一枚。认负不受限制。双方全部放置完毕之前，任何棋子都不得移动。这是你设计初始阵法之网的唯一机会——让棋子彼此支援。

**行棋阶段。**当 32 枚棋子全部立于盘上，双方继续交替行棋（黑方最后布子，因此仍由红方先行）。每回合玩家从下列行动中恰好执行一个：

- **行棋**：把一枚受自己控制的棋子移动到空点。
- **捉**：走向有子的点，声明捉走该棋子的意图。
- **推**：走向有子的点，声明推动它的意图。若推动受阻且任一方有*推转捉*或*被推转被捉*，转为捉子（目标被移除，不受*可被捉*和颜色限制）。若无这些能力，受阻的推动失败。
- **和**：将己方具有*和棋*能力的棋子移动到对方具有*要害*能力的棋子所在位置，将对方棋子移出棋盘并宣布和棋。
- **放置白子**：通过巫放置一枚白子（消耗本回合）。
- **按兵**：放弃移动，跳过回合。由于按兵永远可用，无棋可走绝不会导致告负——不存在困毙判负。双方反复按兵不会产生自动结果；如何了结这种僵局由玩家自行决定。
- **认负**：认输，对局立即以对手获胜结束。

注意：走向有子的点时，必须在行动中声明意图——捉、推或和。

## 终局

对局带有一个持续存在的**胜负**状态：未分、红胜、黑胜、和棋。一旦胜负不再是"未分"，就不再接受任何行动。

每次行棋行动（行棋、捉、推）成功后，都会检查棋盘：

- 若**双方**都没有任何带*要害*能力的棋子（两枚要害棋子在同一次行动中阵亡，例如互毁）→ **和棋**。
- 若红方**没有**任何带*要害*能力的棋子 → 黑胜。
- 若黑方**没有**任何带*要害*能力的棋子 → 红胜。
- 否则 → 对局继续。

尚未放置的要害棋子视为存活。布子阶段不会改变胜负状态。

**和**行动直接将胜负设为和棋，将对方要害棋子移出棋盘。将默认携带*和棋*能力，并通过阵法赋予阵内友军。**认负**直接把胜负设置为对手获胜。这两种行动跳过棋盘检查。

## 战略要点

1. **阵法随子而动，互相生根。**棋盘上的影响力不是静止的——每走一步，整个阵法网络随之位移。要构建能动的阵形：让友军彼此覆盖的同时还能整体推进，关键位置的阵法覆盖要有后备轮换。位置决定了谁覆盖谁，也决定了哪里是弱点。

2. **占位阻挡，控制战场。**占位卡住要道、分割敌军。路径上的每枚棋子都阻挡移动——善加利用这一点。占据空间本身就是一种控制。

3. **推子破坏阵形。**推动与捉子各有用途：捉子消灭敌人，推动则改变敌人的位置。推动可以把关键棋子逐出友军阵法覆盖，挤到不利地形，或割裂对手的阵法连接。推动不消灭敌人本身，却能瓦解敌人赖以作战的网络。

4. **审时度势，攻守有据。**优势时不要冒进——一次脱离友方阵法的追击就能让你最强的棋子变成废铁。劣势时不要放弃——将可以主动走向对方将来和棋，用占位和推子拖慢对手、制造变数。阵棋有和棋出口，翻盘往往比看上去更近。

## 术语表

- **阵法** —— 棋子在以自身为中心的 3×3 区域上投射的影响力场；它改写站在其生效位置上的棋子的能力。
- **阵形** —— 决定周围八个位置中哪些生效的形状：四角、四边、上三角、下三角。
- **能力** —— 棋子可能拥有或缺失的单项本领，例如某个移动方向、捉子、可被捉。所有规则都只作用于能力。
- **友方 / 敌方** —— 与所论棋子颜色相同的棋子，或属于对方玩家颜色的棋子。白子不是任何人的友方。
- **棋池** —— 棋子在盘外等待的地方：布阵前双方各自的棋子，以及共享的白子池。
- **白子** —— 被捉的棋子，回收进共享棋池；任意一方的巫都能把它重新放回棋盘。
- **要害棋子** —— 携带*要害*能力、构成胜负条件的棋子：失去要害棋子的一方告负。通常是将。
- **布阵阶段 / 行棋阶段** —— 对局的两个阶段：先放置所有棋子，然后行棋。
