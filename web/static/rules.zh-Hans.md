# 阵棋 —— 游戏规则

本文描述阵棋的标准对局：9×10 棋盘、红黑双方各 16 枚棋子、空棋盘布阵、红方先行。自定义棋盘和局面的文本格式见 `docs/notation.zh-Hans.md`。

## 目标与一览

阵棋的目标不是将军，而是让对方失去所有带有**要害**能力的棋子。标准棋子中，将是唯一的要害棋子，因此通常表现为“将被移出棋盘的一方输”。自定义配置可以使用其他带有要害能力的棋子，但每方最多一枚。

对局的核心循环很简单：

1. 双方在己方半场布置全部 16 枚棋子。
2. 行棋阶段轮流执行一个行动。
3. 每次行动都根据行动前局面的**有效能力**判定，再把变化写回棋盘。
4. 行动完成后，阵法随新位置重新计算；若要害条件满足，则记录胜负。

阵棋没有九宫、楚河、将军或将死。将像普通棋子一样移动，也可能被捉、被推动或因特殊效果与其他棋子同归于尽。

## 棋盘与布阵

### 棋盘

标准棋盘有 9 列、10 行。列号从左到右为 1–9，行号从上到下为 1–10；位置总是写作“列、行”，例如 `三二` 是第 3 列第 2 行。

- 黑方位于上半区，即第 1–5 行，前进方向向下。
- 红方位于下半区，即第 6–10 行，前进方向向上。
- 所有位置都使用同一套几何规则；不存在宫、河或特殊区域。

### 布阵阶段

对局从空棋盘开始，红方先布阵。双方严格交替，每回合从自己的棋池中取出一枚尚未放置的棋子，放到己方半场的任意空点：

- 红方只能放在第 6–10 行；黑方只能放在第 1–5 行。
- 每枚棋子只能放置一次；标准对局的 16 枚棋子各不相同。
- 布阵阶段不能按兵，也不能放置白子；每回合必须放置己方棋子。
- 认负在布阵阶段也可以使用。

黑方放完最后一枚棋子后，双方棋池都为空，进入行棋阶段；由于最后一次布阵由黑方完成，行棋阶段仍由红方先行。

## 能力与有效能力

规则不把棋子的名字当作特殊判定。名字只是识别棋子的标签；棋子能做什么，由它当前拥有的能力决定。

每枚棋子有一组**基础能力**。棋盘上的邻近阵法会临时改写这些能力，得到行动时真正使用的**有效能力**。能力会随局面变化，不会永久写回棋子本身。

控制组的四枚棋子（将、军、间、谍）都自带*推动友方*和*推动敌方*；下表的“独有基础能力或例外”只列出它们相对于其他棋子的特殊部分。

| 能力 | 含义 |
|---|---|
| **控制（红 / 黑）** | 哪一方可以指挥这枚棋子。没有对应控制权就不能移动它；一枚棋子可以同时受双方控制，也可以暂时不受任何一方控制。 |
| **推动友方** | 可以推动同色棋子。 |
| **推动敌方** | 可以推动异色棋子。 |
| **可被友方推动** | 可以被同色棋子推动。 |
| **可被敌方推动** | 可以被异色棋子推动。 |
| **受阻推动变捉（主动）** | 这枚棋子作为推动方时，若目标无法落地，受阻的推动改为直接捉走目标。该捉子不要求目标可被捉，也不要求双方异色。 |
| **受阻时被捉（被动）** | 这枚棋子作为被推动目标时，若无法落地，推动方可以将它捉走。 |
| **畅通捉子变推动（主动）** | 这枚棋子捉子且到目标的路径没有中间棋子时，只要目标能再落一步，捉子改为推动。 |
| **畅通时被推动（被动）** | 这枚棋子在路径畅通时本应被捉，且能再落一步时，改为被推动。 |
| **捉子** | 具备普通捉子的资格。 |
| **可被捉** | 可以被普通捉子移出棋盘。 |
| **反击** | 这枚棋子被捉时，捉子方也被移出棋盘；它的存在会绕过普通捉子所需的攻击方*捉子*与目标*可被捉*检查。 |
| **同归于尽** | 这枚棋子捉子时，自身也被移出棋盘；它的存在会绕过普通捉子所需的攻击方*捉子*与目标*可被捉*检查。 |
| **任意距离** | 沿已启用的方向走任意步数，而不是只走一步。 |
| **十字方向** | 可以横向或纵向移动。 |
| **斜向** | 可以沿对角线移动。 |
| **日字方向** | 可以按马步移动。 |
| **分兵** | 消耗白子池中的一枚白子，移动到空点，并把该白子留在原位置。 |
| **要害** | 该方失去这枚棋子后，通常立即输掉对局。 |
| **和棋** | 可以走入对方要害棋子所在的位置，移除该棋子并直接宣布和棋。 |

表中的“主动”指棋子发起相应行动时生效；“被动”指棋子作为目标时生效。能力只有在当前有效能力中存在时才适用。

### 判定使用哪一份能力

一次行动使用行动前的棋盘：

1. 先读取起点棋子的有效能力，检查控制权、方向、距离和路径。
2. 若目标有棋子，再读取目标的有效能力，检查推动或捉子的双方条件。
3. 根据落点、阻挡和特殊能力确定实际变化。
4. 应用变化，回收被移出的棋子，再切换行棋方。

行动完成后才重新计算新位置上的阵法。因此，移动到某个点后获得的能力不会追溯改变同一行动的合法性。

## 阵法

### 作用范围与阵形

每枚棋子都有一个以自身为中心的 3×3 邻域，但只有其中八个邻点的一部分生效。中心 `O` 是阵法主人，`X` 是生效位置：

```text
     四角                       四边
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+

    上三角                      下三角
+---+---+---+              +---+---+---+
|   | X |   |              | X |   | X |
+---+---+---+              +---+---+---+
|   | O |   |              |   | O |   |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
```

图按红方视角绘制：红方在下方，向上推进。黑方的阵法上下翻转，因此黑方的“上三角”指向下方，“下三角”指向上方。阵法只影响相邻的生效位置，不影响阵法主人自己。

四种阵形与棋子分组如下：

| 阵形 | 分组 | 棋子 |
|---|---|---|
| 四角 | 控制组 | 将、军、间、谍 |
| 四边 | 移动组 | 车、卒、士、马 |
| 上三角 | 推动组 | 风、山、火、林 |
| 下三角 | 战斗组 | 矛、盾、弹、雷 |

### 阵法叠加

多个阵法可以同时作用于同一枚棋子。它们不是按顺序覆盖，而是同时合成：

- 阵法可以授予一项原本没有的能力，也可以剥夺已有能力。
- 如果有任意一个生效阵法剥夺了同一项能力，剥夺优先，其他阵法不能把它恢复。
- 不同阵法对不同能力的修改可以同时存在；例如一枚棋子可能获得十字方向，却失去捉子能力。
- 控制权也按同样的合成规则处理，因此棋子可能同时受红黑双方控制。

### 白子的例外

白色是中立颜色。在阵法判断“友方”和“敌方”时，白子既不属于红方，也不属于黑方；除军、间、谍明确给予的控制权外，其他阵法不改写白子的能力。白子仍会按照自己的能力参与移动、推动和捉子。

## 移动

棋子必须同时满足以下条件才能移动：

- 行棋方拥有该棋子的有效控制权；
- 棋子拥有与目标方向匹配的方向能力；
- 目标在棋盘内；
- 移动路径没有被棋子阻挡；
- 普通移动或分兵的目标点为空，战斗行动的目标点有棋子。

### 三种方向

- **十字**：横向或纵向。
- **斜向**：对角线方向。
- **日字**：每一步为一个马步。

没有*任意距离*时，每种方向只能走一步。拥有*任意距离*后，可以沿允许的同一方向连续走多步；对日字方向，这表示沿同一条 1:2 斜率的线路连续接力马步。

十字或斜向的长距离移动，起点与终点之间的中间点必须全空。日字移动会检查每个马步的“腿位”：腿位有任何棋子，该马步就被阻挡。连续日字移动的每一段都要满足这项条件。

走向有子的点时，不能使用普通移动意图；必须明确声明是**捉**、**推**还是**和**。相应的文本写法见 `docs/notation.zh-Hans.md`。

## 推动与捉子

推动和捉子是不同的行动意图。它们都先要求起点到目标的移动几何合法、路径可达，再检查互动能力。

### 推动

推动方落到目标原来的位置，目标沿同一移动方向再走一步。被推动棋子是被外力搬动的，因此不需要拥有相应方向能力；但它的落点、出界、占用和日字腿位仍要检查。

- 推动友方：推动方有*推动友方*，**或**目标有*可被友方推动*即可。
- 推动敌方：推动方必须有*推动敌方*，**且**目标必须有*可被敌方推动*。

若目标无法落到下一点，推动受阻。正常情况下，受阻推动失败；如果推动方有*受阻推动变捉*，或目标有*受阻时被捉*，则推动升级为捉子：推动方占据目标原点，目标被移出棋盘。此时不检查普通的*捉子*、*可被捉*或颜色条件，因此也可能移除同色棋子或盾。

用日字方向推动时，目标沿相同的日字向量再走一个马步。例如推动方向从 `(1,1)` 到 `(2,3)`，目标的下一点是 `(3,5)`。

### 普通捉子

普通捉子把攻击方移动到敌方棋子所在点，并将目标移出棋盘。普通捉子要求：

- 双方颜色不同；
- 攻击方有*捉子*，目标有*可被捉*；
- 起点到目标之间没有中间棋子阻挡。

有两项特殊能力可以绕过普通捉子的能力资格检查：

- 攻击方有*同归于尽*时，可以捉没有*捉子*或*可被捉*能力的异色目标，并与目标一起移除；
- 目标有*反击*时，即使攻击方没有*捉子*或目标没有*可被捉*能力，也可以完成捉子，但攻击方会与目标一起移除。

### 捉子转为推动

当捉子路径畅通，且攻击方有*畅通捉子变推动*或目标有*畅通时被推动*时，行动尝试先改为推动。只要目标能落到下一点，就执行推动而不是移除目标；这个转换不再检查普通推动资格。如果下一点无效，则退回普通捉子，不会因为这次转换失败而报错。

### 同归于尽

捉子确定执行后，可能出现双方同时被移除：

- 目标的*反击*生效时，攻击方和目标都被移除。
- 攻击方的*同归于尽*生效时，攻击方和目标都被移除。

这些能力既可以由棋子自身携带，也可以由阵法授予。一次行动中双方都触发时，结果仍是双方都被移除。

## 棋子速查

以下表格列出每枚红黑棋子的基础差异。除表中特别说明外，红黑棋子默认由所属一方控制、可被敌方推动、可被捉；谍还默认同时受另一方控制。阵法效果只针对站在其生效位置上的邻居，不针对棋子自身。

| 棋子 | 基础移动 | 独有基础能力或例外 | 阵法对邻居的效果 |
|---|---|---|---|
| **将** | 十字、任意距离 | 要害、和棋 | 友方获得和棋；敌方失去和棋 |
| **军** | 十字、任意距离 | 分兵 | 白子受军所属方控制；友方获得分兵；敌方失去分兵 |
| **间** | 十字、任意距离 | — | 敌子同时受间所属方控制；友方失去对手控制；白子受间所属方控制 |
| **谍** | 十字、任意距离 | 同时受红黑控制 | 友方同时受对手控制；敌子失去谍所属方的控制；白子受谍对手控制 |
| **车** | 十字、任意距离 | 捉子 | 友方获得任意距离；敌方失去任意距离 |
| **卒** | 十字 | 捉子 | 友方获得十字；敌方失去十字 |
| **士** | 斜向 | 捉子 | 友方获得斜向；敌方失去斜向 |
| **马** | 日字 | 不自带捉子 | 友方获得日字；敌方失去日字 |
| **风** | 斜向、任意距离 | 推动友方、推动敌方 | 友方获得两种推动能力；敌方失去两种推动能力 |
| **山** | 斜向、任意距离 | 可被友方推动；不可被敌方推动 | 友方只能被友方推动；敌方只能被山所属方推动 |
| **火** | 斜向、任意距离 | 推动友方、推动敌方；受阻推动变捉 | 友方获得主动受阻变捉、失去被动受阻变捉；敌方相反 |
| **林** | 斜向、任意距离 | 畅通时被推动（被动） | 友方获得被动转换、失去主动转换；敌方相反 |
| **矛** | 日字、任意距离 | 捉子 | 友方获得捉子；敌方失去捉子 |
| **盾** | 日字、任意距离 | 不可被普通捉子 | 友方失去可被捉；敌方获得可被捉 |
| **弹** | 日字、任意距离 | 同归于尽 | 友方获得同归于尽；敌方失去同归于尽 |
| **雷** | 日字、任意距离 | 反击 | 友方获得反击；敌方失去反击 |

“山”的阵法会同时重写邻居的两项“可被推动”能力；“火”和“林”分别控制受阻推动与畅通捉子的转换；“盾、弹、雷”改变的是捉子资格或捉子后的代价，而不是移动方向。

## 白子与分兵

### 白子从哪里来

白子池只由离场棋子的战斗回收补充。普通捉子、受阻推动升级为捉子、互毁，以及和行动移除的对方要害棋子，都会使共享白子池增加相应数量的白子；认负和分兵都不会产生白子。

白子池在标准开局为空。棋子被回收后，池中数量增加；白子再次被移除时，也会返回池中，因此白子是可循环使用的资源。

### 白子的能力

白子固定拥有：十字、斜向、日字、任意距离、可被捉，以及可被敌方推动。白子没有捉子、分兵、要害、和棋或默认控制权，也没有生效阵法。

白子的控制权只由三种控制组阵法决定：

- 军的阵法让生效位置上的白子受军所属方控制。
- 间的阵法让生效位置上的白子受间所属方控制。
- 谍的阵法让生效位置上的白子受谍的对手控制。

多个控制效果可以叠加，所以白子可能受双方控制，也可能暂时不受任何一方控制。白子的中立身份只影响阵法中的友敌判断；它仍会以白色参与推动和捉子判定。

### 分兵

拥有*分兵*能力的、受当前玩家控制的棋子，可以移动到空点，并从共享白子池取出一枚白子留在原位置。没有可用白子时，分兵失败。

## 回合流程

### 行棋阶段的行动

双方严格交替，每回合恰好执行一个行动：

- **移动**：受控制的棋子移动到空点。
- **捉**：声明移除目标的意图；是否成功由捉子规则决定。
- **推**：声明推动目标的意图；目标落点受阻时可能升级为捉子。
- **和**：具有和棋能力的棋子走入对方要害所在点，直接结束为和棋。
- **分**：消耗白子池中的一枚白子，移动到空点并把该白子留在原位置。
- **按兵**：不移动，跳过本回合。行棋阶段始终可以按兵。
- **认负**：立即认输，对手获胜。

走向空点时，普通移动和分兵的区别必须明确；走向有子时，必须声明捉、推或和，不能把它当作普通移动。

一次行动成功后，行棋方切换。非法行动不会改变棋盘、棋池、行棋方或胜负状态。

### 没有自动困毙判负

按兵始终可用，因此无棋可走不会自动判负。核心规则也不因重复局面、连续按兵或用时自动产生结果；比赛或应用可以在规则之外另行规定这些事项。

## 终局

对局维护一个持续的胜负状态：`未分`、`红胜`、`黑胜`、`和棋`。一旦状态不是`未分`，就不再接受行动。

当一次行动使棋子离开棋盘且没有直接宣布和棋时，根据双方仍拥有的要害棋子确定结果：

- 红黑双方都没有要害棋子：和棋。
- 红方没有要害棋子，黑方仍有：黑胜。
- 黑方没有要害棋子，红方仍有：红胜。
- 双方都仍有：继续。

尚在棋池、尚未布置的要害棋子仍算存活。布阵阶段不会因为棋池变化而提前结束对局。

**和**行动不走普通捉子流程：它要求移动合法、目标是对方的要害棋子、移动方有和棋能力；目标被移除并回收为白子，胜负直接设为和棋。它不要求攻击方有捉子，也不要求目标可被捉。

**认负**直接把胜负设为对手获胜；**按兵**不改变棋盘，也不会自行改变胜负。

## 战略提示

以下内容是分析局面的检查顺序，不是保证有效的定式。阵棋的有效能力会随每一步变化，任何结论都应回到具体局面验证。

1. **先看有效能力，再看棋子名称。**确认当前行棋方控制哪些棋子，逐一检查方向、距离、捉子、推动和特殊转换能力。尤其不要把“这是车/马/矛”当成当前能力的替代品。
2. **先验证路径和落点。**在评估一个战术前，分别检查目标是否为空或有子、路径是否畅通、日字腿位是否被占、推动后的落点是否仍在棋盘内。到得了一个点，不等于能以想要的意图与该点互动。
3. **把阵法依赖当作可被打断的条件。**一个关键能力若只来自单枚邻居，推动、捉子或一次普通移动都可能令它消失；评估计划时，至少确认行动后的替代支持或退路。
4. **推和捉要按最终结果评估。**受阻推动可能变成捉子，畅通捉子可能变成推动，反击和同归于尽还可能让双方同时离场。不要只按“是否吃子”估算交换价值。
5. **把白子池计入局面。**捉子会增加白子池，分兵会消耗白子；白子还可能成为阻挡物或被双方控制。白子的数量和可控制位置，往往会改变下一步能否成立。
6. **优先确认要害与和棋出口。**保护要害不只意味着避免被普通捉子；也要检查双方是否存在合法的和棋行动。若局面有多个可行行动，先排除会立即丢失要害的变化。

## 术语表

- **基础能力** —— 棋子在不考虑邻近阵法时自带的能力。
- **有效能力** —— 基础能力经过当前邻近阵法同时改写后的结果；行动用它判定。
- **阵法** —— 棋子向周围 3×3 邻域的部分位置施加的能力效果。
- **阵形** —— 阵法的覆盖形状：四角、四边、上三角或下三角。
- **控制** —— 哪一方可以指挥一枚棋子；控制权与棋子颜色不是同一概念。
- **棋池** —— 尚未布置的红黑棋子，以及可循环使用的共享白子。
- **白子** —— 颜色为白的中立棋子；白子池只由战斗回收补充，分兵只会取用池中的白子。
- **要害** —— 决定胜负的能力；一方失去全部要害棋子即输。
- **路径畅通** —— 起点与目标之间没有中间棋子；日字移动还必须满足腿位检查。
- **行动意图** —— 对有子目标声明的具体处理方式：捉、推或和。
- **布阵阶段 / 行棋阶段** —— 先放置双方棋子、再执行移动和战斗行动的两个阶段。
