# 阵棋 —— 游戏规则

本文描述标准对局：9×10 棋盘，红黑双方各有 16 枚互不重复的棋子，从空棋盘开始布阵，红方先行。自定义棋盘和局面快照的文本格式见 `docs/notation.zh-Hans.md`。

## 目标与流程

阵棋是一款以局部阵法影响为核心的双人抽象策略游戏。目标是让对方不再拥有带有**首领**能力的棋子。标准棋子中，每方的将（`将`）是唯一的首领棋子。

阵棋没有九宫、楚河、将军或将死。将按普通棋子的规则移动和互动，也可能被捉、在暗捉后被移除，或与另一枚棋子同归于尽。

标准对局分为两个阶段：

1. **布阵阶段**：红黑双方轮流把全部棋子放入己方半场。
2. **行棋阶段**：双方轮流执行一个行棋行动。

每个行动的合法性与效果都以完整的行动前局面为准。相关棋子的**有效能力**在该局面中确定，并用于本次行动；位置变化生效并切换行棋方后，再根据首领棋子的存续状态判断对局是否结束。

## 棋盘与布阵

### 棋盘坐标

标准棋盘有 9 列、10 行。棋子落在棋盘线的交叉点上，每个交叉点最多放一枚棋子。列号从左到右递增，行号从上到下递增。坐标始终按“列、行”书写；文本记谱中的 `三二` 表示第 3 列第 2 行。

- 黑方半场是第 1–5 行，黑方向行号增大的方向前进。
- 红方半场是第 6–10 行，红方向行号减小的方向前进。
- 所有位置使用同一套规则，不存在特殊区域。

自定义棋盘可以是 1×1 到 16×16 的矩形。棋盘高度为奇数时，中间行不属于任何一方的布阵半场。

### 布阵阶段

标准对局从空棋盘开始，双方棋池均为：

```text
将 计 势 变 风 林 火 山 矛 盾 弹 雷 士 卒 马 车
```

红方先布阵，之后双方严格交替。每次布阵从当前玩家的棋池取出一枚棋子，放到己方半场的一个空点。

- 同一枚棋子不能重复放置。
- 红方不能放置黑方棋子，黑方也不能放置红方棋子。
- 当前玩家可以在布阵阶段认负。

标准对局由黑方放完最后一枚棋子。此时双方棋池都为空，进入行棋阶段，并由红方行动。

## 能力与有效能力

棋名只表示棋子的身份，并不单独决定走法。每枚棋子都有一组**基础能力**；周围棋子的阵法会临时改变其中部分能力，形成判断行动是否合法时使用的**有效能力**。

“友方”和“敌方”按棋子的所属玩家（红或黑）判断，不按当前控制权判断。即使黑方能够指挥一枚红子，这枚红子对其他红子仍是友方。

### 基本概念

下文统一使用这些说法：

- **目标**：被本次行动作用的那枚棋子（被捉、被推、被拉，或交换对象）。
- **落点**：一枚棋子行动结束后所占据的交叉点。
- **路径**：从起点到目标点之间经过的交叉点（不含两端）。
- **腿位**：阔步（马步）时，从起点沿长边方向相邻的那个交叉点；它必须为空，否则这一步“蹩马腿”。
- **推动**：推动方落到被推方所在的交叉点，被推方沿同一方向再前进一步。
- **拉动**：拉动方走到一个空点，位于其起点后方一步的棋子被拉到空出的起点。

推动或拉动**友方**棋子时，发动方与被作用的棋子二者之一具备对应能力即可；推动或拉动**敌方**棋子时，两者必须同时具备对应能力。

| 能力 | 含义 |
|---|---|
| **推友** | 可以推动同色棋子。推动方有此能力、或目标有**友推**，二者之一即可。 |
| **推敌** | 可以推动异色棋子。必须推动方有此能力、且目标有**敌推**，两者缺一不可。 |
| **友推** | 允许自己被同色棋子推动。对方推动友方时，即使推动方没有**推友**，只要被推的自己有此能力即可。 |
| **敌推** | 允许自己被异色棋子推动。对方推动敌方时，被推的自己必须有此能力（推动方还须有**推敌**）。 |
| **拉友** | 可以拉动同色棋子。拉动方有此能力、或目标有**友拉**，二者之一即可。 |
| **拉敌** | 可以拉动异色棋子。必须拉动方有此能力、且目标有**敌拉**，两者缺一不可。 |
| **友拉** | 允许自己被同色棋子拉动。对方拉动友方时，即使拉动方没有**拉友**，只要被拉的自己有此能力即可。 |
| **敌拉** | 允许自己被异色棋子拉动。对方拉动敌方时，被拉的自己必须有此能力（拉动方还须有**拉敌**）。 |
| **暗捉** | 发动推动、目标没有合法落点（出界、被占或阔步腿位被堵）时，推动转为捉子：目标离场，推动方落到目标点。推动方有此能力、或目标有**易捉**，二者之一即可。此捉子按普通捉子结算，不触发**强捉**/**反捉**的同归于尽。 |
| **易捉** | 自己被推动且没有合法落点时，被捉掉：自己离场，对方落到此点。自己有此能力、或推动方有**暗捉**，二者之一即可。此捉子按普通捉子结算，不触发同归于尽。 |
| **明捉** | 发动捉子、目标还能沿同一方向再前进一步（落点空且腿位畅通）时，捉子转为推动：己方落到目标点，目标再前进一步。攻击方有此能力、或目标有**难捉**，二者之一即可。 |
| **难捉** | 自己被捉且还能沿同一方向再前进一步时，改为被推动：对方落到己方位置，己方再前进一步。自己有此能力、或攻击方有**明捉**，二者之一即可。 |
| **捕捉** | 可以发动普通捉子：落到目标点，目标离场。要求目标有**被捉**；若己方还有**明捉**或目标有**难捉**，会先检查是否转为推动。 |
| **被捉** | 自己可以作为普通捉子的目标。对方有**捕捉**时即可捉掉自己。 |
| **反捉** | 自己被捉时与攻击方同归于尽，双方都离场。仅在对方无法靠**捕捉**＋自己**被捉**正常捉子、只能靠本能力捉自己时才触发；**暗捉**转来的捉子不触发。 |
| **强捉** | 无视目标是否有**被捉**强行发动捉子，双方同归于尽。但若同时满足**捕捉**＋目标**被捉**（普通捉子），则按普通捉子结算、不同归于尽；**暗捉**转来的捉子不触发。 |
| **疾行** | 沿同一方向连续走多步，直到撞上棋子或棋盘边界。 |
| **纵横** | 可以横向或纵向移动。默认一步；有**疾行**时可连续多步，不能穿过棋子。 |
| **交错** | 可以沿对角线移动。默认一步；有**疾行**时可连续多步，不能穿过棋子。 |
| **阔步** | 可以按“日”字（马步）移动。马步的对应直线腿位必须为空，否则“蹩马腿”不能走；有**疾行**时沿同方向连续走马步，每个落点和腿位都要畅通。 |
| **主动** | 棋子的所属方可以走（指挥）这枚棋子。 |
| **被动** | 棋子的敌方也可以走（指挥）这枚棋子。 |
| **首领** | 计入所属方的存亡条件。某方失去全部**首领**棋子时落败。 |
| **议和** | 走到对方**首领**棋子所在位置（走法合法、路径畅通）时，双方交换位置，对局立即判为和棋。 |

阵法效果只取决于当前局面，生效条件消失后不会继续保留。行动完成后，新位置会产生新的有效能力。只有到达目标点后才获得的能力，不能反过来让刚才的行动合法。

## 阵法

### 局部阵形

阵法只影响阵主周围八个相邻位置中的一部分。`O` 表示阵主，`X` 表示生效点。下图采用红方朝向。

```text
     四角                       四边
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+

    上三角                      下五角
+---+---+---+              +---+---+---+
|   | X |   |              | X |   | X |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
```

黑方阵法按垂直方向翻转。四角和四边翻转后不变；黑方的三角尖端向下，黑方机动组使用向上五边形。正、反两种五边形是同一机动组阵形的双方朝向。阵法永远不会影响中心的阵主自身。

| 分组 | 棋子 | 阵形   |
|---|---|--------|
| **兵法组** | `将 计 势 变` | 四角   |
| **牵制组** | `风 林 火 山` | 四边   |
| **攻守组** | `矛 盾 弹 雷` | 上三角 |
| **机动组** | `士 卒 马 车` | 下五角 |

### 多阵法叠加

同一枚棋子受到的所有相邻阵法都以同一个行动前局面为基础同时生效。

- 每个阵法只影响特定能力。
- 多个阵法对同一能力意见不一致时，关闭能力的一方优先。
- 不同能力彼此独立合并。
- 控制能力也遵循同一规则。友敌关系以每枚棋子的所属方为参照，因此棋子可能同时受双方控制，也可能不受任何一方控制。

## 走法

行棋阶段从棋盘起点发动行动时，必须同时满足：

- 对局尚未结束，且当前处于行棋阶段；
- 当前玩家能够控制起点棋子的有效状态；
- 目标点在棋盘内，且不等于起点；
- 棋子拥有匹配的有效方向；
- 移动距离符合能力；
- 所有路径点和阔步腿位都畅通。

三种方向为：

- **纵横**：横向或纵向一步。
- **交错**：沿对角线一步。
- **阔步**：一个马步（“日”字）。马步的对应直线腿位必须为空，否则“蹩马腿”，这一步不能走。

拥有**疾行**时，可以沿同一方向连续走多步。纵横和交错走多步时不能穿过棋子；阔步走多步时沿同一方向连续走马步，每个中间落点和每个腿位都必须为空。

普通移动和拉要求目标点为空；捉、推、和要求目标点有棋子。行动声明的意图本身就是规则的一部分，到达有子位置并不会自动决定采用哪种互动。

## 行棋行动

### 移动

受控制的棋子移动到空点，不改变其他棋子。

### 捉

捉子要求走法合法，且目标点有棋子。捉子不限制双方所属：只要条件成立，同色棋子也可以互捉。

满足以下任一条件即可发动捉子：

- 攻击方有**捕捉**，且目标有**被捉**（普通捉子）；
- 攻击方有**强捉**（无视目标有没有**被捉**）；
- 目标有**反捉**（被捉时反击）。

发动捉子后，先检查**捉子降级**：若攻击方有**明捉**，或目标有**难捉**，并且目标还能沿同一方向再前进一步（落点在棋盘内、为空，阔步腿位畅通），则本次捉子改为**推动**，不再检查推动条件。目标没有这样的落点时，仍按捉子结算。

按捉子结算时，攻击方落到目标点，目标离开棋盘。**强捉**与**反捉**造成的同归于尽只在下述情况发生：这次捉子不是靠**捕捉**＋**被捉**的普通配对发动，而是靠**强捉**或**反捉**才得手——此时攻击方与目标都离开棋盘。若能普通捉子（同时满足**捕捉**＋**被捉**），则按普通捉子结算，双方都不会同时离场。**暗捉**（推动受阻转捉，见“推”）始终按普通捉子结算，不触发同归于尽。

### 推

推动时，推动方落到被推方的位置，被推方沿同一方向再前进一步。被推方自身不需要移动方向（推动提供外力）；其落点必须在棋盘内、为空，阔步推动时还需腿位畅通。

推动友方与推动敌方的条件不同：

- **推友**：推动同色棋子时，推动方有**推友**，或目标有**友推**，二者之一成立即可。
- **推敌**：推动异色棋子时，推动方有**推敌**，且目标有**敌推**，两者必须同时成立。

目标没有合法落点（出界、被占或阔步腿位被堵）时，推动受阻。此时若推动方有**暗捉**，或目标有**易捉**，推动升级为捉子：推动方落到目标点，目标离开棋盘。这次捉子绕过“捕捉”“被捉”与同异色限制，且始终按普通捉子结算，**强捉**与**反捉**都不生效。没有升级能力时，行动非法。

### 拉

拉动时，拉动方先走到一个空落点；位于其起点后方一步的棋子被拉到空出的起点。

拉动友方与拉动敌方的条件不同：

- **拉友**：拉动同色棋子时，拉动方有**拉友**，或目标有**友拉**，二者之一成立即可。
- **拉敌**：拉动异色棋子时，拉动方有**拉敌**，且目标有**敌拉**，两者必须同时成立。

被拉棋子自身不需要移动方向。其来源位置必须在棋盘内且有棋子；阔步拉还要求来源到起点的腿位畅通。来源缺失或受阻时行动非法。拉不会转换为捉或推。

### 和

和棋行动使用普通走法与路径检查：拥有**议和**的棋子必须能像普通移动一样走到对方**首领**棋子所在的位置（方向、距离、路径、阔步腿位都合法），而不是任意两枚棋子都能交换。

- 这枚棋子必须属于当前玩家，不能只是被当前玩家控制的敌方棋子。
- 目标必须是对方所属的**首领**棋子。

行动成功后，两枚棋子交换位置，对局立即判为和棋。双方都不会离开棋盘，也不会再用物质变化或首领移除结果覆盖这个结果。

### 认负

**认负**在行棋阶段是一个带目标的行动。目标必须是当前玩家能够控制的首领棋子；目标的所属方失败，另一方获胜。通常玩家会让自己的将认负；若`计`使当前玩家能够控制对方的将，也可以让对方的将认负。布阵阶段则由当前玩家直接认负，不需要选择盘上目标，并由当前玩家失败。

本规则不会因为重复局面或用时自动结束。比赛规程可以另行增加这些终局条件。

## 标准棋子

基础能力按**所有棋子共性 → 分组共性 → 棋子特性**确定，后面的规则覆盖前面的规则。

### 所有棋子共性

所有标准棋子默认具有主动、被捉、敌推、敌拉；其他能力默认不具备。

### 分组共性

| 分组 | 棋子 | 阵形 | 增加的能力 |
|---|---|---|---|
| **兵法组** | `将 计 势 变` | 四角 | 交错、疾行、推友、推敌、拉友、拉敌 |
| **牵制组** | `风 林 火 山` | 四边 | 纵横、疾行、推友、推敌、拉友、拉敌 |
| **攻守组** | `矛 盾 弹 雷` | 红方上三角；黑方下三角 | 一步阔步、捕捉 |
| **机动组** | `士 卒 马 车` | 正、反五边形：红方向下，黑方向上 | 捕捉 |

### 棋子特性

每枚棋子自身获得其阵法授予友方的能力，并失去其阵法从友方移除的能力；这一规则可以覆盖全体默认。除此之外，只有将具有首领，车额外具有纵横。

| 棋子 | 阵法效果 |
|---|---|
| **将** | 友方获得议和；敌方失去议和 |
| **计** | 敌方获得“被动”；友方失去“被动” |
| **势** | 友方获得“暗捉”、失去“易捉”；敌方相反 |
| **变** | 友方获得“难捉”、失去“明捉”；敌方相反 |
| **风** | 友方获得“拉友”“拉敌”；敌方失去“拉友”“拉敌” |
| **林** | 友方获得“友拉”、失去“敌拉”；敌方获得“敌拉”、失去“友拉” |
| **火** | 友方获得“推友”“推敌”；敌方失去“推友”“推敌” |
| **山** | 友方获得“友推”、失去“敌推”；敌方获得“敌推”、失去“友推” |
| **矛** | 友方获得“捕捉”；敌方失去“捕捉” |
| **盾** | 友方失去“被捉”；敌方获得“被捉” |
| **弹** | 友方获得“强捉”；敌方失去“强捉” |
| **雷** | 友方获得“反捉”；敌方失去“反捉” |
| **士** | 友方获得“交错”；敌方失去“交错” |
| **卒** | 友方获得“纵横”；敌方失去“纵横” |
| **马** | 友方获得“阔步”；敌方失去“阔步” |
| **车** | 友方获得“疾行”；敌方失去“疾行” |

## 回合完成与终局

合法行动会使规定的变化生效，并切换行棋方。非法行动不会改变棋盘、棋池、行棋方或胜负。

除和棋行动与认负外，其余行动根据行动后双方是否仍保有首领棋子决定结果：

- 双方都不再保有首领棋子：和棋；
- 只有黑方保有首领棋子：黑胜；
- 只有红方保有首领棋子：红胜；
- 双方都保有首领棋子：对局继续。

仍在布阵棋池中的首领棋子也算保有。一旦胜负不再是`未分`，任何后续行动都不合法。

## 局面检查顺序

1. **先看控制权。**棋子所属方与控制方不是一回事；`计`可能让玩家指挥对方棋子。
2. **看有效能力，不只看棋名。**阵法可能移除熟悉的移动或战斗能力，也可能把它授予其他棋子。
3. **先检查走法。**确认路径、每个阔步腿位、推动落点和拉动来源。
4. **完成转换后再计算交换。**受阻推动可能变捉，捕捉可能因明捉或难捉转为推动，弹与雷还可能让双方同时离场。
5. **行动后重新计算阵法。**本次行动中换了位置的任何棋子，都可能一次改变多项能力。
6. **持续检查首领、和棋交换和认负目标。**这些机制不一定通过普通捉走当前玩家自己的将来结束对局。

## 术语表

- **所属方**：棋子标记的红方或黑方。
- **控制**：当前局面中哪一方可以指挥一枚棋子。
- **友方 / 敌方**：同所属方 / 异所属方关系，与控制权无关。
- **基础能力**：棋子在不受阵法影响时具有的能力。
- **有效能力**：基础能力与当前所有相邻阵法效果合并后的结果。
- **阵法**：棋子向相邻特定位置投射的局部能力效果。
- **布阵棋池**：一方尚未进入棋盘的棋子。
- **行动意图**：明确声明的移动、捉、推、拉或和。
- **目标**：被本次行动作用的那枚棋子（被捉、被推、被拉，或交换对象）。
- **落点**：一枚棋子行动结束后所占据的交叉点。
- **路径**：从起点到目标点之间经过的交叉点（不含两端）。
- **腿位**：阔步（马步）时从起点沿长边方向相邻的交叉点；它必须为空，否则“蹩马腿”。
- **首领**：用于决定所属方存亡的能力。
