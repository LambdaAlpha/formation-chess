# 阵棋 —— 游戏规则

[English](rules.md) · [项目概览](../README.zh-Hans.md) · [文本记谱法](notation.zh-Hans.md)

本文描述标准对局：9×10 棋盘，红黑双方各有 16 枚互不重复的棋子，从空棋盘开始布阵，红方先行。自定义棋盘和局面快照的文本格式见[文本记谱法](notation.zh-Hans.md)。

## 目标与流程

阵棋是一款以局部阵法影响为核心的双人抽象策略游戏。目标是让对方不再拥有带有**要害**能力的棋子。标准棋子中，每方的将（`将`）是唯一的要害棋子。

阵棋没有九宫、楚河、将军或将死。将按普通棋子的规则移动和互动，也可能被捉、在受阻推动升级后被移除，或与另一枚棋子同归于尽。

标准对局分为两个阶段：

1. **布阵阶段**：红黑双方轮流把全部棋子放入己方半场。
2. **行棋阶段**：双方轮流执行一个行棋行动。

每个行动的合法性与效果都以完整的行动前局面为准。相关棋子的**有效能力**在该局面中确定，并用于本次行动；位置变化生效并切换行棋方后，再根据要害棋子的存续状态判断对局是否结束。

## 棋盘与布阵

### 棋盘坐标

标准棋盘有 9 列、10 行。列号从左到右递增，行号从上到下递增。坐标始终按“列、行”书写；文本记谱中的 `三二` 表示第 3 列第 2 行。

- 黑方半场是第 1–5 行，黑方向行号增大的方向前进。
- 红方半场是第 6–10 行，红方向行号减小的方向前进。
- 所有位置使用同一套几何规则，不存在特殊区域。

自定义棋盘可以是 1×1 到 16×16 的矩形。棋盘高度为奇数时，中间行不属于任何一方的布阵半场。

### 布阵阶段

标准对局从空棋盘开始，双方棋池均为：

```text
将 计 势 变 风 林 火 山 矛 盾 弹 雷 士 卒 马 车
```

红方先布阵，之后双方严格交替。每次布阵从当前玩家的棋池取出一枚棋子，放到己方半场的一个空点。

- 同一枚棋子不能重复放置。
- 红方不能放置黑方棋子，黑方也不能放置红方棋子。
- 布阵阶段不能按兵。
- 当前玩家可以在布阵阶段认负。

标准对局由黑方放完最后一枚棋子。此时双方棋池都为空，进入行棋阶段，并由红方行动。

## 能力与有效能力

棋名只表示棋子的身份，并不单独决定走法。每枚棋子都有一组**基础能力**；周围棋子的阵法会临时改变其中部分能力，形成判断行动是否合法时使用的**有效能力**。

“友方”和“敌方”按棋子的所属玩家（红或黑）判断，不按当前控制权判断。即使黑方能够指挥一枚红子，这枚红子对其他红子仍是友方。

| 能力 | 含义 |
|---|---|
| **受红方 / 黑方控制** | 对应玩家可以指挥这枚棋子。一枚棋子可以同时受双方控制，也可以暂时不受任何一方控制。 |
| **推动友方 / 敌方** | 主动推动同所属方 / 异所属方棋子的权限。 |
| **可被友方 / 敌方推动** | 被同所属方 / 异所属方棋子推动的被动权限。 |
| **拉动友方 / 敌方** | 主动拉动同所属方 / 异所属方棋子的权限。 |
| **可被友方 / 敌方拉动** | 被同所属方 / 异所属方棋子拉动的被动权限。 |
| **受阻推动变捉（主动）** | 主动升级：推动目标没有合法落点时，推动变为捉子。 |
| **受阻被推变被捉（被动）** | 被动升级：这枚棋子被推且没有合法落点时，推动变为捉子。 |
| **畅通捉子变推（主动）** | 主动降级：捉子时若目标有合法后续落点，捉子变为推动。 |
| **畅通被捉变被推（被动）** | 被动降级：这枚棋子被捉时若有合法后续落点，捉子变为推动。 |
| **捉子** | 普通捉子的主动权限。 |
| **可被捉** | 普通捉子的被动权限。 |
| **被捉反击** | 这枚棋子被捉时，捉子方也被移除；同时绕过攻击方通常需要的“捉子”能力。 |
| **捉子牺牲** | 这枚棋子捉子时，自身也被移除；同时绕过目标通常需要的“可被捉”能力。 |
| **十字** | 横向或纵向移动。 |
| **斜向** | 沿对角线移动。 |
| **日字** | 按马步移动。 |
| **任意距离** | 沿一个已启用方向连续走多步，而不是恰好一步。 |
| **要害** | 这枚棋子计入所属方的存亡条件。 |
| **和棋** | 可以与对方要害棋子交换位置，并立即结束为和棋。 |

阵法效果只取决于当前局面，生效条件消失后不会继续保留。行动完成后，新位置会产生新的有效能力。只有到达目标点后才获得的能力，不能反过来让刚才的行动合法。

## 阵法

### 局部阵形

阵法只影响阵主周围八个相邻位置中的一部分。`O` 表示阵主，`X` 表示生效点。下图采用红方朝向。

```text
     四角                       四边
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+

    上三角                      下五角
+---+---+---+              +---+---+---+
|   | X |   |              | X |   | X |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
```

黑方阵法按垂直方向翻转。四角和四边翻转后不变；黑方的三角尖端向下，黑方机动组使用向上五边形。正、反两种五边形是同一机动组阵形的双方朝向。阵法永远不会影响中心的阵主自身。

| 分组 | 棋子 | 阵形   |
|---|---|--------|
| **兵法组** | `将 计 势 变` | 四角   |
| **牵制组** | `风 林 火 山` | 四边   |
| **攻守组** | `矛 盾 弹 雷` | 上三角 |
| **机动组** | `士 卒 马 车` | 下五角 |

### 多阵法叠加

同一枚棋子受到的所有相邻阵法都以同一个行动前局面为基础同时生效。

- 每个阵法只影响特定能力。
- 多个阵法对同一能力意见不一致时，关闭能力的一方优先。
- 不同能力彼此独立合并。
- 控制能力也遵循同一规则，因此棋子可能同时受双方控制，也可能不受任何一方控制。

## 移动几何

行棋阶段从棋盘起点发动行动时，必须同时满足：

- 对局尚未结束，且当前处于行棋阶段；
- 当前玩家能够控制起点棋子的有效状态；
- 目标在棋盘内，且不等于起点；
- 棋子拥有匹配的有效方向；
- 移动距离符合能力；
- 所有路径点和日字腿位都畅通。

三种方向为：

- **十字**：横向或纵向一步。
- **斜向**：沿对角线一步。
- **日字**：一个马步，且对应直线腿位为空。

拥有**任意距离**时，可以重复同一个步进向量。十字和斜向长距离移动不能穿过棋子；长距离日字移动会沿同一条 1:2 斜率连续走马步，每个中间落点和每个腿位都必须为空。

普通移动和拉要求目标为空；捉、推、和要求目标有棋子。行动声明的意图本身就是规则的一部分，到达有子位置并不会自动决定采用哪种互动。

## 行棋行动

### 移动

受控制的棋子移动到空点，不改变其他棋子。

### 捉

捉子首先要求移动几何合法，且目标点有棋子。捉子不限制双方所属：只要权限成立，同色棋子也可以互捉。

满足以下任一条件即可获得捉子权限：

- 攻击方有**捉子**，目标有**可被捉**；
- 攻击方有**捉子牺牲**；
- 目标有**被捉反击**。

权限成立后，再检查捉子降级。若攻击方有**畅通捉子变推（主动）**，或目标有**畅通被捉变被推（被动）**，并且目标点之后的一步是合法落点，则本次捉子变为推动，不再检查普通推动权限。若该落点不合法，则仍按捉子结算。

最终按捉子结算时，攻击方占据目标点，目标离开棋盘。若存在捉子牺牲或被捉反击，双方都离开棋盘。

### 推

推动方占据有子目标点，目标沿相同移动向量再前进一步。目标自身不需要对应移动方向，因为推动提供外力；但目标落点必须在棋盘内、为空，并在日字推动时满足腿位畅通。

- 推动友方：推动方有**推动友方**，或目标有**可被友方推动**，任一成立即可。
- 推动敌方：推动方有**推动敌方**，且目标有**可被敌方推动**，两者必须同时成立。

目标没有合法落点时，推动受阻。若推动方有**受阻推动变捉（主动）**，或目标有**受阻被推变被捉（被动）**，推动升级为捉子。该升级绕过普通“捉子”“可被捉”和同异色限制，但最终捉子仍会触发捉子牺牲与被捉反击。没有升级能力时，行动非法。

### 拉

主动棋子先移动到一个空目标点；位于起点后方、与主动移动向量相反一整步的位置上的棋子，被拉入刚刚空出的起点。

- 拉动友方：主动方有**拉动友方**，或目标有**可被友方拉动**，任一成立即可。
- 拉动敌方：主动方有**拉动敌方**，且目标有**可被敌方拉动**，两者必须同时成立。

被拉棋子自身不需要对应移动方向。其来源位置必须在棋盘内且有棋子；日字拉还要求来源到起点的腿位畅通。来源缺失或受阻时行动非法。拉不会转换为捉或推。

### 和

和棋行动使用普通移动几何和路径检查，但不使用捉子或推动权限。

- 主动棋子必须属于当前玩家，不能只是被当前玩家控制的敌方棋子。
- 主动棋子必须拥有**和棋**能力。
- 目标必须是对方所属的要害棋子。

行动成功后，两枚棋子交换位置，胜负立即设为和棋。双方都不会离开棋盘，也不会再用物质变化或要害移除结果覆盖这个和棋。

### 按兵与认负

**按兵**在尚未结束的行棋阶段始终合法，且必须声明为当前玩家按兵。它不改变任何棋盘位置。由于按兵始终可用，本规则不存在“没有其他合法行动时自动判负”。

**认负**在行棋阶段是一个带目标的行动。目标必须是当前玩家能够控制的要害棋子；目标棋子的所属方失败，另一方获胜。通常玩家会让自己的将认负；若`计`使当前玩家能够控制对方的将，也可以让对方的将认负。布阵阶段则由当前玩家直接认负，不需要选择盘上目标，并由当前玩家失败。

本规则不会因为重复局面、连续按兵或用时自动结束。比赛规程可以另行增加这些终局条件。

## 标准棋子

基础能力按**所有棋子共性 → 分组共性 → 棋子特性**确定，后面的规则覆盖前面的规则。

### 所有棋子共性

所有标准棋子默认受所属方控制、可被捉、可被敌方推拉；其他能力默认不具备。

### 分组共性

| 分组 | 棋子 | 阵形 | 增加的能力 |
|---|---|---|---|
| **兵法组** | `将 计 势 变` | 四角 | 斜向、任意距离、可推拉友敌 |
| **牵制组** | `风 林 火 山` | 四边 | 十字、任意距离、可推拉友敌 |
| **攻守组** | `矛 盾 弹 雷` | 红方上三角；黑方下三角 | 一步日字、捉子 |
| **机动组** | `士 卒 马 车` | 正、反五边形：红方向下，黑方向上 | 捉子 |

### 棋子特性

每枚棋子自身获得其阵法授予友方的能力，并失去其阵法从友方移除的能力；这一规则可以覆盖全体默认。除此之外，只有将具有要害，车额外具有十字。

| 棋子 | 阵法效果 |
|---|---|
| **将** | 友方获得和棋；敌方失去和棋 |
| **计** | 敌方获得计所属方控制；友方失去对方控制 |
| **势** | 友方获得受阻推动变捉（主动）、失去受阻被推变被捉（被动）；敌方相反 |
| **变** | 友方获得畅通被捉变被推（被动）、失去畅通捉子变推（主动）；敌方相反 |
| **风** | 友方获得两种主动拉能力；敌方失去两种主动拉能力 |
| **林** | 友方只能被友方拉；敌方只能被林所属方拉 |
| **火** | 友方获得两种主动推能力；敌方失去两种主动推能力 |
| **山** | 友方只能被友方推；敌方只能被山所属方推 |
| **矛** | 友方获得捉子；敌方失去捉子 |
| **盾** | 友方失去可被捉；敌方获得可被捉 |
| **弹** | 友方获得捉子牺牲；敌方失去捉子牺牲 |
| **雷** | 友方获得被捉反击；敌方失去被捉反击 |
| **士** | 友方获得斜向；敌方失去斜向 |
| **卒** | 友方获得十字；敌方失去十字 |
| **马** | 友方获得日字；敌方失去日字 |
| **车** | 友方获得任意距离；敌方失去任意距离 |

## 回合完成与终局

合法行动会使规定的变化生效，并切换行棋方。非法行动不会改变棋盘、棋池、行棋方或胜负。

除和棋行动与认负外，其余行动根据行动后双方是否仍保有要害棋子决定结果：

- 双方都不再保有要害棋子：和棋；
- 只有黑方保有要害棋子：黑胜；
- 只有红方保有要害棋子：红胜；
- 双方都保有要害棋子：对局继续。

仍在布阵棋池中的要害棋子也算保有。一旦胜负不再是`未分`，任何后续行动都不合法。

## 局面检查顺序

1. **先看控制权。**棋子所属方与控制方不是一回事；`计`可能让玩家指挥对方棋子。
2. **看有效能力，不只看棋名。**阵法可能移除熟悉的移动或战斗能力，也可能把它授予其他棋子。
3. **先检查几何。**确认主动路径、每个日字腿位、推动落点和拉动来源。
4. **完成转换后再计算交换。**受阻推动可能变捉，畅通捉子可能变推，弹与雷还可能让双方同时离场。
5. **行动后重新计算阵法。**主动棋子或被外力移动的棋子换位，都可能一次改变多项能力。
6. **持续检查要害、和棋交换和认负目标。**这些机制不一定通过普通捉走当前玩家自己的将来结束对局。

## 术语表

- **所属方**：棋子标记的红方或黑方。
- **控制**：当前局面中哪一方可以指挥一枚棋子。
- **友方 / 敌方**：同所属方 / 异所属方关系，与控制权无关。
- **基础能力**：棋子在不受阵法影响时具有的能力。
- **有效能力**：基础能力与当前所有相邻阵法效果合并后的结果。
- **阵法**：棋子向相邻特定位置投射的局部能力效果。
- **布阵棋池**：一方尚未进入棋盘的棋子。
- **行动意图**：明确声明的移动、捉、推、拉或和。
- **要害**：用于决定所属方存亡的能力。
