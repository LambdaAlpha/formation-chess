## 设计理念

在大多数棋类游戏里，棋子的名字就决定了它是什么：象走斜线、马走日字——身份是固定的，对局在这些固定身份的互动中展开。阵棋采用了不同的思路。每枚棋子都投射一个**阵法**——覆盖自身周围区域的专属影响力场。站在他人阵法之内的棋子，其能力会被暂时重塑：可能获得新的力量，也可能失去原本拥有的能力。

这意味着没有任何棋子永远"只是它自己"。卒站在车旁，忽然就能不限距离地滑行；将的身边若全是失去捉子能力的敌人，它便固若金汤。棋盘上的影响力此消彼长，每一步都会重构局部的力量之网。

规则中没有任何绑定在棋子名字上的逻辑——一切机制皆是**能力**。马并非"因为是马所以走日字"，它只是默认携带日字移动能力，正如炮默认携带跳吃。任何站在马的阵法中的棋子都可以获得同样的日字移动；而误入敌方炮阵的炮，会失去自己的跳吃。规则只关心能力，不关心名字。

## 如果你会下象棋

阵棋沿用了象棋的 9×10 棋盘和许多熟悉的棋子名称——车、马、炮、卒、将——以及两个标志性机制：马腿会被蹩住，炮隔着炮架跳吃。

除此之外的一切都不同。没有九宫，没有楚河汉界，也没有固定开局——军队由你亲手布置。棋子没有固定的本领：一枚棋子能做什么，由它所处的阵法决定。没有将军与将死——将像普通棋子一样被捉，失去将即输掉对局。被捉的棋子也不会永远退场：它们化为白子，可被任意一方的巫重新召回棋盘。

## 基础

对局在 **9 路 × 10 行的棋盘**上进行，双方为**红方**与**黑方**。每名玩家统率 **16 枚各不相同的棋子**。此外还有第三种颜色——**白色**，属于被捉后可重新部署的棋子（见[白子](#白子)）。

棋盘上的位置写作（列，行）：列号 1–9 自左向右，行号 1–10 自上而下。黑方在棋盘上方作战（第 1–5 行），红方在下方（第 6–10 行）。

对局分两个阶段：双方先把所有棋子**布置**上盘，然后**行棋**。**红方先行**，双方严格交替，每回合一个行动，从第一步布子直到对局结束。

## 能力

每枚棋子都拥有一组决定其行为的**能力**。能力并非一成不变——它们会被阵法改写。完整的能力列表：

| 能力 | 效果 |
|---|---|
| **控制（红 / 黑）** | 决定哪名玩家可以指挥这枚棋子。只有受你控制的棋子才能由你移动。 |
| **推动友方** | 可以把友方棋子沿移动方向再推一步。 |
| **推动敌方** | 可以把敌方棋子沿移动方向再推一步。 |
| **可被友方推动** | 可以被友方棋子推动。 |
| **可被敌方推动** | 可以被敌方棋子推动。 |
| **穿越友方** | 移动时可以穿过友方棋子占据的点。 |
| **穿越敌方** | 移动时可以穿过敌方棋子占据的点。 |
| **可被友方穿越** | 可以被友方棋子穿过。 |
| **可被敌方穿越** | 可以被敌方棋子穿过。 |
| **捉子** | 可以走入敌方棋子所在点并将其提离棋盘。 |
| **可被捉** | 可以被敌方棋子捉走。 |
| **被捉反杀** | 这枚棋子被捉时，捉它的棋子同归于尽（报复型互毁）。 |
| **捉子同亡** | 这枚棋子捉子时，自身一并阵亡（自损型互毁）。 |
| **跳吃** | 可以越过恰好一枚中间棋子捉走敌方棋子（炮的机制）。 |
| **任意距离** | 沿允许的方向可滑行任意步数，而非只走一步。 |
| **方向：十字** | 可以横向或纵向移动。 |
| **方向：斜向** | 可以沿对角线移动。 |
| **方向：日字** | 可以按日字（马步）移动。 |
| **控制白子** | 可以把白子池中的白子放置到自身阵法内的空点上。指挥已放置的白子则由巫的阵法效果另行授予。 |
| **要害** | 失去携带此能力的棋子即告负。将默认携带它。 |

## 阵法

每枚棋子都在以自身为中心的 3×3 区域上投射**阵法**。站入这片区域的棋子可能被改写能力。但阵法并非均匀的力场：其中只有特定位置生效，具体哪些位置取决于棋子的**阵形**。

阵形共有四种：

```
     四角                       四边
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
|   | O |   |              | X | O | X |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+

    上三角                      下三角
+---+---+---+              +---+---+---+
|   | X |   |              | X |   | X |
+---+---+---+              +---+---+---+
|   | O |   |              |   | O |   |
+---+---+---+              +---+---+---+
| X |   | X |              |   | X |   |
+---+---+---+              +---+---+---+
```

`O` 是站在中心的阵法主人；`X` 是生效的位置。

每种阵形对应一组四枚棋子：

- **四角** —— 控制组：将、巫、叛、谍
- **四边** —— 移动组：车、卒、犬、马
- **上三角** —— 推动与穿越组：河、山、风、林
- **下三角** —— 攻杀组：矛、盾、炮、雷

可以这样理解：棋子的影响力以特定的**形状**向外辐射。四角棋子沿对角线施加影响，如同居于侧翼纵览战场的主帅；四边棋子沿正方向施加影响，如同扼守四方要道的步兵。三角阵形则是不对称的：上三角覆盖正前方与后方两翼，下三角覆盖前方两翼与正后方。

**阵法叠加的合成规则：**当多个阵法试图修改同一枚棋子的同一项能力时，遵循"**只要有阵法禁用该能力，禁用即获胜**"的规则合成。哪怕只有一个阵法剥夺了某项能力，其他阵法也无法将其恢复。禁用是绝对的。

## 移动

棋子只能沿其**方向**能力所启用的方向移动。方向共有三类：十字（横/纵）、斜向、日字（马步）。

默认情况下，每个方向只能移动**一步**：

- 十字：向左、右、上、下移动一点。
- 斜向：沿对角线移动一点。
- 日字：走一个马步。

拥有**任意距离**能力后，棋子可沿允许的方向滑行任意点数。对日字移动而言，这意味着沿同一条斜线连续接力马步。

棋子必须至少拥有一个方向能力才能移动。敌方阵法可以剥夺方向能力——一旦离开友方掩护误入敌阵，随时可能动弹不得。**务必保持你的阵法网络完整**，让友军彼此支援。

## 推动、穿越与捉子

这三类互动由成对的能力共同约束。

**推动**是指把目标棋子沿你的移动方向再往前送一步。推动是外力：被推的棋子被视为拥有所需的方向能力，其自身的移动能力无关紧要。只有当被推棋子在物理上无法完成这一步时——落点被占或出界，或去路被它无法穿越的棋子挡住——推动才会失败，并升级为一次捉子尝试（目标必须带有*可被捉*才能捉成；否则推动被判无效）。

- 推动**友方**棋子：你拥有*推动友方***或**目标拥有*可被友方推动*，任意一方同意即可。
- 推动**敌方**棋子：你拥有*推动敌方***且**目标拥有*可被敌方推动*，双方条件缺一不可。

**穿越**是指路过挡路棋子时视其如无物。但你不能停在有子的点上。

- 穿越**友方**棋子：你拥有*穿越友方***或**挡路者拥有*可被友方穿越*。
- 穿越**敌方**棋子：你拥有*穿越敌方***且**挡路者拥有*可被敌方穿越*。

**普通捉子**是指走入敌方棋子所在的点并将其提离棋盘。你需要*捉子*，目标需要*可被捉*，且双方颜色不同。路径必须畅通（沿途所有棋子都必须可被穿越）。

**跳吃**（炮的机制）是越过恰好一枚中间棋子完成捉子。你需要*跳吃*，目标需要*可被捉*，且路径上恰好有一枚棋子。这枚中间棋子可否穿越无关紧要——它是炮架，不是被穿越的对象。

**互毁：**任何捉子完成后，可能触发两种效果：

- 若目标带有*被捉反杀*，捉子方一并被提离。
- 若捉子方带有*捉子同亡*，捉子方一并被提离。

这两种效果对任何站在授予它们的阵法之内的棋子都生效，而不仅限于默认携带者。

### 日字移动的特殊情形

日字移动是跃过一个中间点抵达终点，而非贴着棋盘滑行，因此有三处机制略有不同：

**蹩马腿。**日字移动在通往终点的路上会经过一个中间点。例如从 (1,1) 走到(2,3) 会经过 (1,2)。若该点被你无法穿越的棋子占据，移动便被阻挡——马腿被蹩住了。能否越过挡路棋子，由上文的穿越规则决定。

**用日字移动推子。**用日字移动推动目标时，目标沿同一方向再走一个马步。例如从 (1,1) 往 (2,3) 方向推，目标落到 (3,5)。被推棋子走这一步如同自己移动——无须拥有日字能力，但马腿按被推棋子自身的穿越能力判定：若腿位被不可穿越的棋子占据，或落点被占，推动升级为捉子。

**用日字路径跳吃。**炮可以沿日字路径跳吃：越过蹩腿的棋子，捉住更远处的目标。蹩腿棋子在此充当炮架，与直线跳吃完全一致。

## 棋子

每方拥有 16 枚各不相同的棋子，按阵形分为四组。

默认情况下，所有红黑棋子均带有*可被敌方推动*、*可被敌方穿越*、*可被捉*；仅有的例外是**山**（不可被敌方推动）与**林**（不可被敌方穿越）。换言之，除非阵法改写这些设定，大多数棋子都可以被敌方推动、穿越与捉走。

### 控制组 —— 四角阵形

这一组棋子沿十字方向任意距离移动，其阵法关乎**谁控制什么**。

| 棋子 | 默认能力 | 阵法效果 |
|---|---|---|
| **将** | 十字、任意距离、*要害* | 不修改任何能力——但见下文 |
| **巫** | 十字、任意距离、*控制白子* | 阵内白子受巫所属玩家控制 |
| **叛** | 十字、任意距离 | 阵内敌子**同时**受叛所属玩家控制（策反） |
| **谍** | 十字、任意距离、双方玩家皆可控制 | 阵内友军**同时**可被对手控制（双面间谍效果） |

**将**是你的要害棋子——失去将即告负。它行动自由，但不能捉子、不能推动、不能穿越其他棋子，请用阵法保护它。它自己的阵法不修改任何能力，但它的阵形依然重要：两将一旦站进彼此的阵法，对局即以和棋结束（见[终局](#终局)）。

**巫**让阵亡的棋子重返战场：它把白子放置到自身阵法内的空点上，而站在其阵法内的白子听命于巫所属的玩家。见[白子](#白子)。

### 移动组 —— 四边阵形

这一组棋子拥有各自名号的移动方向，外加捉子能力。它们的阵法**为友军授予移动能力，并从敌军身上剥夺之**。

| 棋子 | 默认能力 | 阵法效果 |
|---|---|---|
| **车** | 十字、任意距离、捉子 | 友军获得任意距离；敌军失去之（被钉在一步） |
| **卒** | 十字、捉子 | 友军获得十字移动；敌军失去之 |
| **犬** | 斜向、捉子 | 友军获得斜向移动；敌军失去之 |
| **马** | 日字、捉子 | 友军获得日字移动；敌军失去之 |

这一组棋子是全军机动力的支柱，而且彼此支援：除车以外它们默认一步一步地走，但站在友方车的旁边就能获得无限射程。车的阵法还能钉子：阵内的敌方棋子会失去滑行能力。

### 推动与穿越组 —— 上三角阵形

这一组棋子沿十字方向任意距离移动，专精于**推动与穿越机制**。

| 棋子 | 默认能力 | 阵法效果 |
|---|---|---|
| **河** | 十字、任意距离、*推动友方*、*推动敌方* | 友军获得两种推动能力；敌军两者皆失 |
| **山** | 十字、任意距离、*可被友方推动*、**无**"可被敌方推动" | 友军：仅可被友军推动；敌军：仅可被山的一方推动 |
| **风** | 十字、任意距离、*穿越友方*、*穿越敌方* | 友军获得两种穿越能力；敌军两者皆失 |
| **林** | 十字、任意距离、*可被友方穿越*、**无**"可被敌方穿越" | 友军：仅可被友军穿越；敌军：仅可被林的一方穿越 |

河与风为周围的棋子赋能——去推动、去穿越；山与林则完全接管周围棋子"如何被作用"的方式，把两项"可被推动"（或"可被穿越"）能力一并改写，敌我皆然。

### 攻杀组 —— 下三角阵形

这一组棋子沿十字方向任意距离移动，专精于**捉子与战斗**。

| 棋子 | 默认能力 | 阵法效果 |
|---|---|---|
| **矛** | 十字、任意距离（没有捉子！） | 友军获得捉子；敌军失去之 |
| **盾** | 十字、任意距离 | 友军变得不可被捉（免疫）；敌军变得可被捉 |
| **炮** | 十字、任意距离、跳吃 | 友军获得跳吃；敌军失去之 |
| **雷** | 十字、任意距离、*被捉反杀*、*捉子同亡* | 阵内所有棋子获得这两种效果——任何捉子都变成同归于尽 |

**矛**自身没有捉子能力，但它的阵法让友军获得捉子、让敌军失去捉子。**盾**保护身边的所有友军——让盾靠近你的将，叠上一层免疫。**炮**只能跳吃，永远需要一枚棋子在自己与目标之间充当炮架。**雷**把周围变成谁都不敢先动手的禁区。

## 白子

任何棋子因战斗被提离棋盘——无论是被普通捉走，还是死于互毁效果——都会化为共享白子池中的一枚**白子**。白子只有十字移动（一步），任何人都可以捉它，它自己不能捉子。

拥有**控制白子**能力的棋子（巫）可以把白子池中的白子放置到其阵法内的任意空点。白子自身不带任何控制权：它们通过巫的阵法受指挥——站在巫的阵法内的白子可由该巫所属的玩家移动（若双方的巫同时覆盖它，则双方都能移动它）；不在任何巫的阵法内的白子无法被移动。捉走白子会将其送回白子池——白子是循环使用的，不会被消灭。

这为游戏增加了第三个维度：被你捉走的敌子化为白子，可被我方巫重新部署。不过白子不受阵法效果影响，战力远不如原棋子——主要用于占位和阻挡。

## 对局流程

**布阵阶段。**对局从空棋盘开始。自红方起，双方轮流每回合把一枚己方棋子放置到己方半场的任意空点上：红方放在第 6–10 行，黑方放在第 1–5 行。此阶段不允许按兵和认负，也不能放置白子——每个回合都必须放置己方 16 枚棋子中的一枚。双方全部放置完毕之前，任何棋子都不得移动。这是你设计初始阵法之网的唯一机会——让棋子彼此支援。

**行棋阶段。**当 32 枚棋子全部立于盘上，双方继续交替行棋（黑方最后布子，因此仍由红方先行）。每回合玩家从下列行动中恰好执行一个：

- **行棋**：把一枚受自己控制的棋子移动到空点。
- **捉**：走向有子的点，声明捉走该棋子的意图。
- **推**：走向有子的点，声明推动它的意图。推动受阻时，自动转为捉子尝试。
- **放置白子**：通过巫放置一枚白子（消耗本回合）。
- **按兵**：放弃移动，跳过回合。由于按兵永远可用，无棋可走绝不会导致告负——不存在困毙判负。双方反复按兵不会产生自动结果；如何了结这种僵局由玩家自行决定。
- **认负**：认输，对局立即以对手获胜结束。

注意：走向有子的点时，必须在行动中声明意图——捉或推。

## 终局

对局带有一个持续存在的**胜负**状态：未分、红胜、黑胜、和棋。一旦胜负不再是"未分"，就不再接受任何行动。

每次行动成功后——包括布子——都会检查棋盘：

- 若**双方**都没有任何带*要害*能力的棋子（两枚要害棋子在同一次行动中阵亡，例如互毁）→ **和棋**。
- 若红方**没有**任何带*要害*能力的棋子 → 黑胜。
- 若黑方**没有**任何带*要害*能力的棋子 → 红胜。
- 若双方要害棋子俱在，且两枚要害棋子恰好站在彼此的阵法之内 → **和棋**（两将确认了彼此的位置，同意休战）。
- 否则 → 对局继续。

尚未放置的要害棋子视为存活。由于该检查在布阵阶段同样进行，和棋可以直接产生于布子——例如两将隔着边界被放进彼此的阵法。

认负直接把胜负设置为对手获胜，跳过棋盘检查。

## 战略要点

1. **阵法随子而动，互相生根。**棋盘上的影响力不是静止的——每走一步，整个阵法网络随之位移。要构建能动的阵形：让友军彼此覆盖的同时还能整体推进，关键位置的阵法覆盖要有后备轮换。位置决定了谁覆盖谁，也决定了哪里是弱点。

2. **占位与穿越，控制战场。**占位卡住要道、分割敌军；穿越跨越地形、连络友军。两者互为表里——谁能穿过一个路口由布局决定，一个位置值不值得占由穿越能力决定。

3. **推子破坏阵形。**推动与捉子各有用途：捉子消灭敌人，推动则改变敌人的位置。推动可以把关键棋子逐出友军阵法覆盖，挤到不利地形，或割裂对手的阵法连接。推动不消灭敌人本身，却能瓦解敌人赖以作战的网络。

4. **审时度势，攻守有据。**优势时不要冒进——一次脱离友方阵法的追击就能让你最强的棋子变成废铁。劣势时不要放弃——双将照面即是和棋，用占位和推子拖慢对手、制造变数。阵棋有和棋出口，翻盘往往比看上去更近。

## 术语表

- **阵法** —— 棋子在以自身为中心的 3×3 区域上投射的影响力场；它改写站在其生效位置上的棋子的能力。
- **阵形** —— 决定周围八个位置中哪些生效的形状：四角、四边、上三角、下三角。
- **能力** —— 棋子可能拥有或缺失的单项本领，例如某个移动方向、捉子、可被捉。所有规则都只作用于能力。
- **友方 / 敌方** —— 与所论棋子颜色相同的棋子，或属于对方玩家颜色的棋子。白子不是任何人的友方。
- **棋池** —— 棋子在盘外等待的地方：布阵前双方各自的棋子，以及共享的白子池。
- **白子** —— 被捉的棋子，回收进共享棋池；任意一方的巫都能把它重新放回棋盘。
- **要害棋子** —— 携带*要害*能力、构成胜负条件的棋子：失去要害棋子的一方告负。通常是将。
- **炮架** —— 跳吃所越过的那枚唯一的中间棋子。
- **布阵阶段 / 行棋阶段** —— 对局的两个阶段：先放置所有棋子，然后行棋。
